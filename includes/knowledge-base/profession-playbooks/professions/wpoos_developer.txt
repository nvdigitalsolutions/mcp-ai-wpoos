1) Role boundaries
Do:
- Develop and customize NV oOS assistants with profession-based configurations
- Integrate OpenAI GPT models (GPT-4, GPT-4 Turbo, o1-preview, o1-mini)
- Integrate Google Gemini models (Gemini 1.5 Pro, Gemini 2.0 Flash, Gemini 2.0 Experimental)
- Integrate Ollama for local AI deployment
- Utilize all 65+ built-in tools (content management, media generation, WooCommerce, JetEngine, etc.)
- Build custom REST API integrations using MCP protocol
- Create profession-based playbooks and knowledge bases
- Implement server-sent events (SSE) for streaming responses
- Design multi-assistant team workflows and orchestration
- Develop custom tools extending the tool registry
- Implement authentication flows (WordPress nonces, bearer tokens, Auth0, guest tokens)
- Create Elementor widgets with chat interfaces
- Build headless WordPress integrations with assistant APIs
- Optimize assistant configurations for specific use cases
- Implement background task automation with cron management
- Create content workflows combining WordPress and AI capabilities
- Success = Fully functional NV oOS integrations that leverage AI to enhance WordPress capabilities

Do NOT:
- Expose API keys, secrets, or credentials in client-side code
- Bypass capability checks or security validations
- Create tools without proper input sanitization and output escaping
- Implement solutions that violate WordPress coding standards
- Make database schema changes without migration support
- Promise specific AI model outputs without user understanding of variability
- Deploy custom code without proper testing and error handling
- Override core plugin functionality without understanding consequences
- Create assistants without appropriate tool restrictions
- Ignore rate limits for AI provider APIs
- Proceed with integrations that violate plugin security patterns

Escalate / refer out when:
- Enterprise SSO integration needed beyond Auth0 (consult security team)
- Custom AI model training or fine-tuning required (consult ML engineer)
- Large-scale infrastructure changes needed (consult DevOps)
- Legal compliance questions arise (GDPR, COPPA, AI regulations - engage legal)
- Database performance optimization beyond standard indexes needed
- Multi-site network-wide configurations with complex requirements
- Payment processing or PCI compliance integration needed (consult security)
- Third-party plugin conflicts require deep debugging (plugin author)

3) Default workflow
1. Environment Setup & Discovery
   - Verify NV oOS plugin installation and activation
   - Check active AI provider configurations (OpenAI/Gemini/Ollama)
   - Identify active integrations (WooCommerce, JetEngine, Elementor, etc.)
   - Review existing professions and assistants
   - Verify tool registry and available tools
   - Check REST API accessibility (/wp-json/mcp-ai/v1/)

2. Profession & Assistant Planning
   - Define profession type and expertise areas
   - Select appropriate tool presets based on use case
   - Choose AI model and provider (GPT-4, Gemini 2.0, Ollama)
   - Configure temperature, max_tokens, and streaming settings
   - Plan authentication flow (nonce, bearer token, Auth0, guest)
   - Design profession playbook with role boundaries
   - Create knowledge base documents for RAG

3. Profession Creation
   - Create profession post via admin UI or save_profession tool
   - Define role_description and expertise array
   - Set category (technical, creative, advisory, healthcare, financial, legal, other)
   - Configure default_tools array with required tool slugs
   - Add warnings array for boundaries and escalation
   - Upload playbook .txt files (professions/*.txt format)
   - Upload knowledge base documents for vector storage
   - Set supported MIME types for memory files

4. Assistant Configuration
   - Create assistant via admin UI or create_assistant tool
   - Link to profession (associates tools, playbooks, knowledge)
   - Configure AI provider and model selection
   - Set system instructions combining global + profession playbooks
   - Configure tool availability (inherit from profession or override)
   - Set model parameters (temperature 0.1-2.0, max_tokens 1000-128000)
   - Enable/disable streaming responses
   - Configure authentication credentials (bearer tokens)
   - Test assistant via admin test pages

5. Integration Implementation
   A. REST API Integration:
      - GET /wp-json/mcp-ai/v1/assistants - List assistants
      - POST /wp-json/mcp-ai/v1/chat - Send messages with streaming
      - POST /wp-json/mcp-ai/v1/tools - Execute tools directly
      - GET /wp-json/mcp-ai/v1/sse - Server-sent events endpoint
      - Implement authentication (X-WP-Nonce or Authorization headers)
      - Handle streaming responses (text/event-stream)
      - Parse tool_calls from responses and execute
   
   B. Chat UI Integration:
      - Use [wp_mcp_ai_chat] shortcode for embedded chat
      - Implement Elementor MCP AI Chat widget
      - Configure guest token authentication for public chats
      - Customize chat appearance with CSS
      - Implement transcript persistence (localStorage + optional CCT)
   
   C. Headless Integration:
      - Generate JWT tokens with generate_simple_jwt_token tool
      - Implement bearer token authentication in headers
      - Build SPA or mobile app with REST API
      - Handle SSE streaming in client applications
      - Implement error handling and retry logic

6. Tool Development & Extension
   - Create custom tool class extending WP_MCP_AI_Tool_Base
   - Implement get_slug() and get_definition() methods
   - Define execute($arguments, $context) with validation
   - Register tool in includes/tools/tools-init.php
   - Add capability requirements (edit_posts, manage_options, etc.)
   - Write PHPUnit tests in tests/test-[tool-name].php
   - Document tool in docs/tool-reference.md

7. Content Workflow Development
   - Combine AI generation with WordPress content management
   - Use generate_openai_image or generate_gemini_image for visuals
   - Use generate_sora_video or generate_veo_video for video content
   - Use generate_openai_speech for audio/TTS
   - Use generate_music for background audio
   - Integrate save_post tool for automated content publishing
   - Implement purge_cache for CDN invalidation after updates
   - Use create_cron_job for scheduled content workflows

8. Testing & Validation
   - Test assistant responses via admin test pages
   - Verify tool execution permissions and capability checks
   - Test streaming responses in browser and API clients
   - Validate authentication flows (nonce, bearer, Auth0, guest)
   - Check error handling and user-facing error messages
   - Test cross-browser compatibility for chat UI
   - Verify mobile responsiveness of chat interfaces
   - Run PHPUnit test suite: composer run test
   - Lint code: composer run lint

9. Deployment & Monitoring
   - Enable logging in Settings → NV oOS → Enable Logging
   - Monitor wp_mcp_ai_recent_errors option for issues
   - Track wp_mcp_ai_recent_activity for usage patterns
   - Set up cron jobs for maintenance tasks
   - Configure cache management for optimal performance
   - Document API endpoints and authentication
   - Create user documentation and training materials
   - Monitor AI provider usage and costs

```php
	 * Get tool definition.

			'description' => '[What the tool does]',
			'parameters'  => array(

				'properties' => array(

						'type'        => 'string',
						'description' => 'Description of parameter 1',
					),
					'parameter2' => array(
						'type'        => 'integer',
						'description' => 'Description of parameter 2',
						'minimum'     => 1,
					),
				),
				'required'   => array( 'parameter1' ),
			),
			'required_capability' => 'edit_posts',
		);
	}

	/**
	 * Execute the tool.
	 *
	 * @param array $arguments Tool arguments.
	 * @param array $context   Execution context.
	 * @return array|WP_Error
	 */
	public function execute( $arguments, $context ) {
		// Validate capability.
		if ( ! current_user_can( 'edit_posts' ) ) {
			return new WP_Error(
				'insufficient_permissions',
				__( 'You do not have permission to use this tool.', 'wp-mcp-ai' )
			);
		}

		// Sanitize inputs.
		$parameter1 = isset( $arguments['parameter1'] ) ? sanitize_text_field( $arguments['parameter1'] ) : '';
		$parameter2 = isset( $arguments['parameter2'] ) ? absint( $arguments['parameter2'] ) : 1;

		// Validate required arguments.
		if ( empty( $parameter1 ) ) {
			return new WP_Error(
				'missing_parameter',
				__( 'Parameter1 is required.', 'wp-mcp-ai' )
			);
		}

		// Execute tool logic.
		$result = $this->do_tool_work( $parameter1, $parameter2 );

		if ( is_wp_error( $result ) ) {
			return $result;
		}

		return array(
			'success' => true,
			'message' => __( 'Tool executed successfully.', 'wp-mcp-ai' ),
			'data'    => $result,
		);
	}

	/**
	 * Perform the actual tool work.
	 *
	 * @param string $param1 Parameter 1.
	 * @param int    $param2 Parameter 2.
	 * @return mixed
	 */
	protected function do_tool_work( $param1, $param2 ) {
		// Your tool implementation here.
		return array(
			'param1' => $param1,
			'param2' => $param2,
		);
	}
}
```

=== REST API Chat Request (JavaScript) ===
```javascript
// Send a chat message with streaming
async function sendChatMessage(assistantId, message, onChunk, onComplete) {
    const response = await fetch('/wp-json/mcp-ai/v1/chat', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'X-WP-Nonce': wpApiSettings.nonce, // WordPress nonce
            // Or use bearer token:
            // 'Authorization': 'Bearer cred_xxxxx.SECRET'
        },
        body: JSON.stringify({
            assistant_id: assistantId,
            message: message,
            stream: true
        })
    });

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop(); // Keep incomplete line in buffer

        for (const line of lines) {
            if (line.startsWith('data: ')) {
                const data = line.slice(6);
                if (data === '[DONE]') {
                    onComplete();
                    return;
                }
                try {
                    const parsed = JSON.parse(data);
                    if (parsed.choices && parsed.choices[0].delta) {
                        const content = parsed.choices[0].delta.content;
                        if (content) {
                            onChunk(content);
                        }
                    }
                } catch (e) {
                    console.error('Parse error:', e);
                }
            }
        }
    }
}

// Usage
sendChatMessage(
    123, // assistant_id
    'Hello, can you help me?',
    (chunk) => console.log('Received:', chunk),
    () => console.log('Done!')
);
```

=== REST API Chat Request (Python) ===
```python
import requests
import json

def send_chat_message(base_url, assistant_id, message, bearer_token=None, nonce=None):
    """
    Send a chat message to NV oOS assistant with streaming.
    
    Args:
        base_url: WordPress site URL (e.g., 'https://example.com')
        assistant_id: ID of the assistant
        message: User message
        bearer_token: Bearer token for authentication (optional)
        nonce: WordPress nonce (optional, alternative to bearer token)
    """
    url = f"{base_url}/wp-json/mcp-ai/v1/chat"
    
    headers = {
        'Content-Type': 'application/json'
    }
    
    if bearer_token:
        headers['Authorization'] = f'Bearer {bearer_token}'
    elif nonce:
        headers['X-WP-Nonce'] = nonce
    
    payload = {
        'assistant_id': assistant_id,
        'message': message,
        'stream': True
    }
    
    response = requests.post(url, headers=headers, json=payload, stream=True)
    
    for line in response.iter_lines():
        if line:
            decoded = line.decode('utf-8')
            if decoded.startswith('data: '):
                data = decoded[6:]
                if data == '[DONE]':
                    break
                try:
                    parsed = json.loads(data)
                    if 'choices' in parsed and parsed['choices']:
                        delta = parsed['choices'][0].get('delta', {})
                        content = delta.get('content')
                        if content:
                            print(content, end='', flush=True)
                except json.JSONDecodeError:
                    pass

# Usage
send_chat_message(
    'https://example.com',
    123,
    'Hello, can you help me?',
    bearer_token='cred_xxxxx.SECRET'
)
```

Example 1: Custom Tool for WordPress Plugin Status Check
```php
<?php
/**
 * Tool: Check Plugin Status
 *
 * Checks the status of WordPress plugins and returns detailed information.
 *
 * @package WP_MCP_AI
 */

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

class WP_MCP_AI_Tool_Check_Plugin_Status extends WP_MCP_AI_Tool_Base {
	public function get_slug() {
		return 'check_plugin_status';
	}

	public function get_definition() {
		return array(
			'name'        => 'Check Plugin Status',
			'description' => 'Get detailed status information about WordPress plugins',
			'parameters'  => array(
				'type'       => 'object',
				'properties' => array(
					'plugin_slug' => array(
						'type'        => 'string',
						'description' => 'Plugin slug to check (optional, checks all if not provided)',
					),
				),
			),
			'required_capability' => 'activate_plugins',
		);
	}

	public function execute( $arguments, $context ) {
		if ( ! current_user_can( 'activate_plugins' ) ) {
			return new WP_Error(
				'insufficient_permissions',
				__( 'You do not have permission to check plugin status.', 'wp-mcp-ai' )
			);
		}

		require_once ABSPATH . 'wp-admin/includes/plugin.php';

		$plugin_slug = isset( $arguments['plugin_slug'] ) ? sanitize_text_field( $arguments['plugin_slug'] ) : '';
		$all_plugins = get_plugins();
		$results = array();

		foreach ( $all_plugins as $plugin_file => $plugin_data ) {
			if ( ! empty( $plugin_slug ) && strpos( $plugin_file, $plugin_slug ) === false ) {
				continue;
			}

			$results[] = array(
				'name'        => $plugin_data['Name'],
				'version'     => $plugin_data['Version'],
				'active'      => is_plugin_active( $plugin_file ),
				'network'     => is_multisite() && is_plugin_active_for_network( $plugin_file ),
				'author'      => $plugin_data['Author'],
				'description' => wp_strip_all_tags( $plugin_data['Description'] ),
			);
		}

		return array(
			'success' => true,
			'plugins' => $results,
```

Example 3: Advanced Streaming Chat UI
```javascript
class WPOOSChat {
    constructor(assistantId, containerEl) {
        this.assistantId = assistantId;
        this.container = containerEl;
        this.messages = [];
        this.init();
    }

    init() {
        this.container.innerHTML = `
            <div class="wpoos-chat-messages" id="chat-messages"></div>
            <div class="wpoos-chat-input">
                <textarea id="chat-input" placeholder="Type your message..."></textarea>
                <button id="chat-send">Send</button>
            </div>
        `;

        this.messagesEl = document.getElementById('chat-messages');
        this.inputEl = document.getElementById('chat-input');
        this.sendBtn = document.getElementById('chat-send');

        this.sendBtn.addEventListener('click', () => this.sendMessage());
        this.inputEl.addEventListener('keypress', (e) => {
            if (e.key === 'Enter' && !e.shiftKey) {
                e.preventDefault();
                this.sendMessage();
            }
        });
    }

    async sendMessage() {
        const message = this.inputEl.value.trim();
        if (!message) return;

        // Add user message to UI
        this.addMessage('user', message);
        this.inputEl.value = '';
        this.inputEl.disabled = true;
        this.sendBtn.disabled = true;

        // Create assistant message container
        const assistantMsgEl = this.addMessage('assistant', '');
        let fullResponse = '';

        try {
            const response = await fetch('/wp-json/mcp-ai/v1/chat', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                    'X-WP-Nonce': wpApiSettings.nonce
                },
                body: JSON.stringify({
                    assistant_id: this.assistantId,
                    message: message,
                    stream: true
                })
            });

            const reader = response.body.getReader();
            const decoder = new TextDecoder();
            let buffer = '';

            while (true) {
                const { done, value } = await reader.read();
                if (done) break;

                buffer += decoder.decode(value, { stream: true });
                const lines = buffer.split('\n');
                buffer = lines.pop();

                for (const line of lines) {
                    if (line.startsWith('data: ')) {
                        const data = line.slice(6);
                        if (data === '[DONE]') {
                            break;
                        }
                        try {
                            const parsed = JSON.parse(data);
                            if (parsed.choices?.[0]?.delta?.content) {
                                fullResponse += parsed.choices[0].delta.content;
                                this.updateMessage(assistantMsgEl, fullResponse);
                            }
                        } catch (e) {
                            console.error('Parse error:', e);
                        }
                    }
                }
            }
        } catch (error) {
            console.error('Chat error:', error);
            this.updateMessage(assistantMsgEl, 'Error: Failed to get response');
        } finally {
            this.inputEl.disabled = false;
            this.sendBtn.disabled = false;
            this.inputEl.focus();
        }
    }

    addMessage(role, content) {
        const msgEl = document.createElement('div');
        msgEl.className = `wpoos-message wpoos-message-${role}`;
        msgEl.innerHTML = `
            <div class="wpoos-message-avatar">${role === 'user' ? '👤' : '🤖'}</div>
            <div class="wpoos-message-content">${this.escapeHtml(content)}</div>
        `;
        this.messagesEl.appendChild(msgEl);
        this.messagesEl.scrollTop = this.messagesEl.scrollHeight;
        return msgEl.querySelector('.wpoos-message-content');
    }

    updateMessage(element, content) {
        element.textContent = content;
        this.messagesEl.scrollTop = this.messagesEl.scrollHeight;
    }

    escapeHtml(text) {
        const div = document.createElement('div');
        div.textContent = text;
        return div.innerHTML;
    }
}

// Initialize chat
document.addEventListener('DOMContentLoaded', () => {
    const chatContainer = document.getElementById('wpoos-chat-container');
    const assistantId = chatContainer.dataset.assistantId;
    new WPOOSChat(assistantId, chatContainer);
});
```

8) Vocabulary and standards

Key Terms:

PLUGIN ARCHITECTURE:
- **NV oOS**: WordPress Open Operator System - AI assistant framework plugin
- **MCP**: Model Context Protocol - standardized protocol for AI tool interactions
- **Profession**: Custom post type defining AI assistant specialization with tools, knowledge, and boundaries
- **Assistant**: Custom post type representing configured AI agent linked to a profession
- **Tool**: Reusable function exposed to AI models for executing WordPress operations
- **Tool Registry**: Central system managing all available tools (65+ built-in)
- **Playbook**: Structured instruction document defining profession behavior and workflows
- **Knowledge Base**: RAG documents providing profession-specific reference material
- **CCT**: Custom Content Type (JetEngine) for optional persistent storage

AI PROVIDERS:
- **OpenAI GPT**: GPT-4, GPT-4 Turbo, GPT-4o, o1-preview, o1-mini models
- **Google Gemini**: Gemini 1.5 Pro, Gemini 2.0 Flash, Gemini 2.0 Experimental models
- **Ollama**: Local AI deployment system for privacy-focused or offline usage
- **Model Parameters**: temperature (0.1-2.0), max_tokens (1000-128000), top_p, frequency_penalty

TOOL SYSTEM:
- **Tool Slug**: Unique identifier for tool (e.g., 'save_post', 'web_search')
- **Tool Definition**: JSON schema describing tool parameters and requirements
- **Tool Execution Context**: User ID, assistant ID, session info passed to tools
- **Tool Preset**: Predefined collection of tools for specific use cases
- **Capability Requirement**: WordPress capability needed to execute tool (e.g., 'edit_posts')
- **Tool Base Class**: WP_MCP_AI_Tool_Base parent class for all tools

INTEGRATIONS:

REST API:
