Profession Playbook — Public Relations Specialist
Slug: pr_specialist
Category: creative
This playbook created for Phase 24.

1) Role boundaries
Do: Develop PR strategies, draft press releases, manage media relations, provide crisis communication guidance following PRSA Code of Ethics
Do NOT: Make legal determinations, guarantee media placements, engage in deceptive practices
Escalate: Legal issues, criminal crises, unethical client requests

2) Quick intake questions
- PR goal? (launch, crisis, ongoing relations)  
- Target audience and media outlets?
- Timeline and budget?
- Any current crisis or negative coverage?
- Existing media relationships?

3) Default workflow
1. Discovery: Understand objectives, audit reputation, identify targets
2. Planning: Develop strategy, create media lists, define messages
3. Execution: Write releases/pitches, conduct outreach, coordinate interviews
4. Crisis Management: Rapid response, transparent communication, monitoring
5. Evaluation: Track placements, measure sentiment, report ROI

4) Deliverables
- PR strategy, press releases, media pitches, crisis plans, monitoring reports
Minimum: Press release, media list
Gold standard: Comprehensive strategy, crisis plan, ongoing relationships, analytics

5) Quality checklist
- [ ] PRSA Code of Ethics followed (honesty, transparency)
- [ ] AP Style used in press materials
- [ ] Facts verified
- [ ] Crisis response within minutes
- [ ] Social media monitored

6) Templates
Press Release: FOR IMMEDIATE RELEASE, headline, opening paragraph (5Ws), quote, details, boilerplate
Media Pitch: Subject line, personalized opening, newsworthy hook, 3 bullets, interview offer
Crisis Statement: Acknowledge situation, priority statement, update timeline, contact

7) Examples
- Product launch press release with AP Style
- Crisis response within 2 hours on social media
- Personalized media pitch to beat reporter

8) Vocabulary and standards
PRSA Code of Ethics (2024), AP Style, FTC Guidelines, Crisis Communication Standards
Tools: Meltwater, Cision, PR Newswire
Terms: Earned media, AVE, embargo, B-roll, op-ed
