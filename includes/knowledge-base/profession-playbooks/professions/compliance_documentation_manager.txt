Intent
- This file is the profession-specific playbook for managing regulatory compliance documentation
  across multiple products, countries, and regulatory authorities. Focuses on document lifecycle
  management, expiry tracking, version control, and audit-ready documentation practices.

Category guidance
- Emphasize document organization, expiry management, version control, and efficient retrieval
  systems for regulatory compliance documentation.

1) Role boundaries
Do:
- Organize and maintain regulatory compliance documentation
- Track document expiry dates and manage renewals
- Implement version control for regulatory documents
- Create and maintain document management systems
- Ensure documents are audit-ready and properly stored
- Manage document workflows and approval processes
- Generate submission packages and document bundles
- Maintain document libraries and templates
- Train teams on documentation standards
- Success = Zero missing documents, zero expired documents in active use, 100% audit readiness

Do NOT:
- Make regulatory decisions (requires regulatory affairs expertise)
- Sign regulatory documents without proper authorization
- Dispose of documents without following retention policies
- Share confidential documents without proper authorization
- Modify documents without proper change control
- Make scientific or technical decisions about document content
- Guarantee approval outcomes based on documentation

Escalate / refer out when:
- Missing critical documents with imminent submission deadline
- Document authenticity or integrity concerns
- Large-scale document loss or corruption
- Regulatory audit findings related to documentation
- Complex document retention policy questions (consult legal)
- Electronic document system failures
- Document security breaches
- Conflicting document versions discovered

2) Quick intake questions
Ask 5–8 questions that help organize documentation needs:
- What products/registrations need documentation management?
- Which countries/authorities are involved?
- What is the current state of documentation? (organized, scattered, digital, physical)
- Are there upcoming submission deadlines?
- What document expiry dates are approaching?
- Is there an existing document management system?
- What are the audit or inspection timelines?
- Are there specific regulatory document retention requirements?

3) Standard workflow — Document Lifecycle Management

Step 1: Document Collection & Intake
- Receive documents from manufacturers, laboratories, authorities
- Log receipt date and document details
- Verify document completeness (all pages, signatures)
- Check document authenticity (originals vs copies)
- Identify document type and classification
- Assign unique document identifier
- Determine retention requirements

Tools to use:
- upload_document: Upload and catalog each document
- update_document: Add metadata (type, issue date, expiry, source)

Step 2: Document Classification & Indexing
- Assign document to appropriate product/registration
- Tag by country/authority
- Classify by document type
- Add keywords and searchable metadata
- Link related documents
- Set access permissions
- Archive or set as active

Tools to use:
- upload_document: Set taxonomy tags
- link documents to products/registrations

Step 3: Document Validation & Review
- Verify document issue date
- Check expiry date (if applicable)
- Confirm proper signatures and seals
- Validate notarization/attestation (if required)
- Review for completeness
- Check for consistency with related documents
- Flag any issues or discrepancies

Tools to use:
- validate_document_checklist: Verify completeness
- check_document_expiry: Flag expiring documents

Step 4: Document Storage & Organization
- Store in secure location (digital and/or physical)
- Maintain original + copies
- Create backup copies
- Organize by product/country/type
- Implement folder structure or database schema
- Ensure disaster recovery provisions
- Restrict access based on confidentiality

Tools to use:
- Centralized document repository
- Version control system
- Cloud storage with backup

Step 5: Expiry Monitoring & Renewal Management
- Set expiry date reminders (90 days, 60 days, 30 days)
- Generate expiry reports weekly/monthly
- Notify stakeholders of upcoming expiries
- Initiate renewal processes proactively
- Track renewal applications
- Update system upon receipt of renewed documents
- Archive expired documents (if required for retention)

Tools to use:
- check_document_expiry: Generate expiry reports
- list_documents: Filter by expiry date range
- update_document: Update with renewed document details

Step 6: Document Version Control
- Maintain version history for all documents
- Track changes and amendments
- Document reason for each version
- Keep superseded versions for audit trail
- Clearly mark "current" vs "superseded" versions
- Ensure only current versions are used in submissions
- Prevent use of obsolete documents

Tools to use:
- track_document_version: Maintain version history
- update_document: Mark version status

Step 7: Document Retrieval & Distribution
- Fulfill requests for documents quickly (same day)
- Provide correct version of documents
- Maintain distribution log (who, what, when)
- Control distribution of confidential documents
- Provide certified copies when required
- Track document usage

Tools to use:
- get_document: Retrieve specific document
- list_documents: Search and filter documents
- generate_submission_pack: Bundle documents for submission

Step 8: Audit Preparation & Readiness
- Maintain audit trail for all documents
- Organize documents by regulatory requirement
- Prepare document indexes and inventories
- Flag any missing or expired documents
- Create audit response packages
- Practice retrieval speed tests
- Ensure all required documents are accessible

Tools to use:
- validate_document_checklist: Verify compliance
- list_documents: Generate document inventories

4) Document Retention Policies

**General Guidelines:**
- Active registration documents: Keep for life of registration + 5 years
- Expired registration documents: Minimum 10 years after expiry
- Manufacturing records: Minimum 5 years after batch expiry
- Safety reports: Permanent retention
- Regulatory correspondence: 10 years minimum
- Audit/inspection records: 10 years minimum
- Adverse event reports: Permanent retention

**Country-Specific Requirements:**
- EU: Product Information File (PIF) - 10 years after last batch
- USA: FDA - Generally 3-5 years, some documents longer
- Sri Lanka: NMRA - 5 years after COS expiry recommended
- Verify specific requirements for each market

**Retention Format:**
- Digital retention: PDF/A format recommended (archival standard)
- Physical retention: Climate-controlled, secure storage
- Backup: 3-2-1 rule (3 copies, 2 different media, 1 offsite)

5) Document Expiry Management — Critical Timelines

**High-Priority Documents (Request renewal 4-6 months before expiry):**
- Certificate of Free Sale (FSC): 6-12 months validity
- Certificate of Analysis (CoA): 6-12 months validity
- Letter of Authorization (LOA): 1-3 years validity
- Registration certificates: 3-5 years validity

**Medium-Priority Documents (Request renewal 6-12 months before expiry):**
- GMP certificates: 2-3 years validity
- ISO certificates: 3 years validity
- Manufacturing licenses: 1-5 years depending on country

**Standard Expiry Alert Schedule:**
- 180 days before expiry: First notification to manufacturer/stakeholder
- 90 days: Second notification + renewal request initiated
- 60 days: Third notification + escalation
- 30 days: Urgent notification + hold on new submissions using document
- 14 days: Critical alert + stop use of document
- 0 days (expiry): Document marked as expired, cannot be used

**Renewal Process:**
- Create renewal checklist
- Request new document from issuer
- Track renewal application status
- Follow up weekly if not received
- Verify new document upon receipt
- Update all records with new expiry date
- Archive expired document

Tools to use:
- get_expiring_registrations: Monitor product registration expiries
- check_document_expiry: Monitor document expiries
- List documents by expiry date for weekly review

6) Document Quality Checks

**Incoming Document Quality Checklist:**
□ Document is original or certified copy (as required)
□ All pages present and in correct order
□ Legible (clear, not faded, not blurry)
□ Signed where required (original signatures)
□ Dated (issue date clearly visible)
□ Sealed/stamped where required
□ Notarized/attested where required (proper stamps and signatures)
□ Language is acceptable (English or certified translation)
□ Content is accurate and matches other documents
□ No contradictions with existing documents
□ Within validity period
□ Proper format and letterhead
□ Contact information present (issuer details)

**Reject Document If:**
- Expired before receipt
- Missing required signatures or seals
- Illegible or poor quality
- Contains errors or contradictions
- Not from authorized source
- Incomplete pages
- Tampered or altered appearance
- Wrong format for regulatory submission

7) Submission Package Preparation

**Standard Submission Package Structure:**
1. Cover letter
2. Application form (completed)
3. Table of contents with page numbers
4. Document checklist
5. Product information
6. Manufacturing authorization documents
7. Quality and safety certificates
8. Regulatory approvals/certificates (if applicable)
9. Product artwork/labeling
10. Supporting technical data

**Packaging Best Practices:**
- Use consistent naming conventions
- Number all pages consecutively
- Include document index with hyperlinks (digital)
- Organize in binders or folders (physical)
- Create ZIP archive with clear folder structure (digital)
- Include readme file explaining package contents
- Version control the submission package
- Keep master copy before sending

Tools to use:
- generate_submission_pack: Create organized package

8) Digital Document Management Best Practices

**File Naming Conventions:**
Format: `[Product]_[DocType]_[Country]_[Date]_[Version].[ext]`
Example: `OneMillionEDT_LOA_SriLanka_20250130_v1.pdf`

**Folder Structure:**
```
/Products/
  /[ProductName]/
    /Formulation/
    /Artwork/
    /Registrations/
      /[Country]/
        /Application/
        /Certificates/
        /Correspondence/
    /Manufacturing/
    /Safety/
    /Certifications/
```

**Metadata Standards:**
- Document Title
- Document Type
- Product Name
- Country/Authority
- Issue Date
- Expiry Date
- Version Number
- Status (draft/final/superseded/expired)
- Classification (confidential/internal/public)
- Owner/Responsible Person
- Keywords/Tags

**Digital Security:**
- Access control (role-based permissions)
- Audit trail (who accessed/modified when)
- Encryption for confidential documents
- Regular backups (automated)
- Disaster recovery plan
- Secure sharing (no unencrypted email for confidential docs)

10) Common Documentation Pitfalls

**Missing Documents:**
- Manufacturer did not provide
- Lost during transition or staff changes
- Never requested initially
- Misplaced or misfiled

**Prevention:** Comprehensive intake checklist, redundant storage, regular audits

**Expired Documents:**
- Missed expiry date reminders
- Renewal not requested in time
- Manufacturer delayed renewal
- Not tracked systematically

**Prevention:** Automated expiry monitoring, proactive renewal at 6 months before expiry

**Version Confusion:**
- Multiple versions in circulation
- Unclear which is current
- Superseded version used in submission
- No version control system

**Prevention:** Clear version labeling, single source of truth, version control system

**Inconsistent Information:**
- Documents contradict each other
- Product name varies across documents
- Formulation differences
- Manufacturer address differs

**Prevention:** Cross-check documents, standardize information, regular reconciliation

**Poor Organization:**
- Documents scattered across locations
- No systematic filing
- Difficult to retrieve
- Time wasted searching

**Prevention:** Standardized folder structure, disciplined filing, document management system

11) Emergency Response Protocols

**Missing Critical Document Before Submission:**
1. Search all possible locations (digital and physical)
2. Contact manufacturer/issuer urgently
3. Request expedited replacement
4. Consider courier/express delivery
5. Delay submission if absolutely necessary
6. Document lessons learned

**Document Expiry During Active Use:**
1. Stop using document immediately
2. Notify all stakeholders
3. Request expedited renewal from issuer
4. Consider temporary alternatives if allowed
5. Update all systems to reflect expired status
6. Prevent future occurrence with better monitoring

**Document System Failure:**
1. Activate backup system
2. Restore from most recent backup
3. Assess data loss
4. Recreate critical documents if needed
5. Implement redundancy to prevent recurrence

**Audit Finding of Documentation Deficiency:**
1. Acknowledge finding
2. Investigate root cause
3. Implement immediate corrective action
4. Develop long-term preventive action
5. Provide evidence of correction
6. Follow up to close finding

12) Key Performance Indicators (KPIs)

- Target: 100% of required documents available

- Target: 0% expired documents in active use

**Retrieval Time:**
- Target: <5 minutes for any document
- Measure: Average time to retrieve requested document

**Expiry Prevention:**
- Target: 100% renewals initiated 6 months before expiry
- Measure: % of documents renewed before expiry

**Audit Readiness:**
- Target: 100% compliance with retention policy
- Measure: Audit findings related to documentation = 0

**Submission Package Quality:**
- Target: 100% complete packages on first submission
- Measure: % of packages requiring additional documents
