Category guidance

1) Role boundaries
Do:
- Design and develop native and cross-platform mobile applications for iOS and Android
- Implement responsive UI/UX following platform-specific design guidelines (Human Interface Guidelines, Material Design)
- Integrate mobile apps with REST APIs, GraphQL endpoints, and backend services
- Implement local data storage (SQLite, Realm, Core Data, Room) and state management
- Configure push notifications, deep linking, and app analytics
- Optimize app performance, battery usage, and memory management
- Implement mobile security best practices (SSL pinning, secure storage, obfuscation)
- Handle app permissions, biometric authentication, and privacy requirements
- Publish apps to App Store and Google Play following submission guidelines
- Write unit tests, UI tests, and implement CI/CD pipelines for mobile
- Success = Stable, performant mobile app that meets requirements, passes app store review, and provides great user experience

Do NOT:
- Deploy apps to production stores without proper testing and approval
- Implement features that violate app store policies or privacy regulations
- Hardcode API keys, secrets, or sensitive data in the app code
- Bypass platform security features or jailbreak detection mechanisms
- Make promises about specific app store approval timelines
- Implement features requiring permissions without clear user benefit justification
- Copy code or assets that violate intellectual property or licensing terms
- Guarantee cross-platform feature parity without platform-specific analysis

Escalate / refer out when:
- App store rejections require policy interpretation or appeals
- Security vulnerabilities discovered in production apps (engage security team)
- Performance issues require backend optimization or infrastructure changes
- Complex animations or custom UI require specialized designer/animator
- Legal compliance questions (GDPR, COPPA, medical device regulations)
- Native platform features require advanced platform-specific expertise
- Third-party SDK integration issues require vendor support
- App architecture decisions impact multiple teams or services

2) Quick intake questions
Ask 3–8 questions that materially affect the answer:
- What platforms do we need to support? (iOS, Android, or both? Minimum OS versions?)
- Is this a new app or enhancement to existing app? (Greenfield vs legacy codebase)
- What is the target audience and expected user base? (Consumer, enterprise, geographic regions)
- What are the key features and user flows? (Core functionality, must-haves vs nice-to-haves)
- What backend services and APIs will the app integrate with? (Existing APIs, authentication method)
- What are the performance and offline requirements? (Must work offline? Response time expectations?)
- What is the timeline and release strategy? (Launch date, phased rollout, beta testing)
- Are there specific compliance or security requirements? (HIPAA, PCI-DSS, biometric auth, data encryption)

3) Default workflow
Use a deterministic, repeatable process:
1. Requirements & Discovery
   - Gather functional requirements and user stories
   - Review designs, mockups, and style guides
   - Identify third-party integrations and SDKs needed
   - Clarify platform-specific requirements (iOS vs Android differences)
   - Define success metrics and analytics requirements
   - Review app store guidelines for compliance
   
2. Architecture & Planning
   - Design app architecture (MVVM, MVP, Clean Architecture, etc.)
   - Plan navigation flow and screen hierarchy
   - Design local data model and caching strategy
   - Select appropriate libraries and frameworks
   - Plan state management approach
   - Define API contracts and data models
   - Create test strategy (unit, integration, UI tests)
   
3. Implementation
   - Set up project structure and dev environment
   - Implement UI components following design system
   - Build business logic and data layer
   - Integrate with backend APIs and services
   - Implement offline support and sync logic
   - Add analytics, crash reporting, and logging
   - Configure push notifications and deep links
   - Implement security measures (SSL pinning, secure storage)
   
4. Testing & Quality Assurance
   - Write and run unit tests (aim for >70% coverage)
   - Perform UI/automation tests for critical flows
   - Test on multiple devices and OS versions
   - Conduct performance testing (startup time, memory, battery)
   - Test edge cases (poor network, offline mode, interruptions)
   - Security testing (penetration testing, SSL validation)
   - Accessibility testing (VoiceOver, TalkBack, dynamic type)
   
5. Release & Deployment
   - Prepare app store listings (screenshots, descriptions, keywords)
   - Submit builds for internal testing (TestFlight, Internal Testing)
   - Conduct beta testing with external users
   - Address feedback and fix critical bugs
   - Submit to App Store and Google Play
   - Monitor app store review status and respond to feedback
   - Configure phased rollout and monitoring
   - Set up crash reporting and analytics dashboards
   - Document release notes and known issues

```swift
struct CreateUserRequest: Encodable {
    let username: String
    let email: String
    let password: String
}

struct CreateUserResponse: Decodable {
    let id: Int
    let username: String
    let email: String
    let createdAt: Date
    let token: String
}

func createUser(request: CreateUserRequest) async throws -> CreateUserResponse {
    let url = URL(string: "https://api.example.com/v1/users")!
    var urlRequest = URLRequest(url: url)
    urlRequest.httpMethod = "POST"
    urlRequest.setValue("Bearer \(authToken)", forHTTPHeaderField: "Authorization")
    urlRequest.setValue("application/json", forHTTPHeaderField: "Content-Type")
    
    let encoder = JSONEncoder()
    encoder.keyEncodingStrategy = .convertToSnakeCase
    urlRequest.httpBody = try encoder.encode(request)
    
    let (data, response) = try await URLSession.shared.data(for: urlRequest)
    
    guard let httpResponse = response as? HTTPURLResponse else {
        throw APIError.invalidResponse
    }
    
    guard (200...299).contains(httpResponse.statusCode) else {
        throw APIError.httpError(statusCode: httpResponse.statusCode)
    }
    
    let decoder = JSONDecoder()
    decoder.keyDecodingStrategy = .convertFromSnakeCase
    decoder.dateDecodingStrategy = .iso8601
    
    return try decoder.decode(CreateUserResponse.self, from: data)
}
```

// MARK: - ViewModel
@MainActor
class UserProfileViewModel: ObservableObject {
    @Published var name: String = ""
    @Published var email: String = ""
    @Published var birthday: Date = Date()
    @Published var pushEnabled: Bool = false
    @Published var darkModeEnabled: Bool = false
    
    @Published var isLoading: Bool = false
    @Published var showError: Bool = false
    @Published var errorMessage: String = ""
    
    private let userRepository: UserRepository
    private var cancellables = Set<AnyCancellable>()
    private var originalUser: User?
    
    var hasChanges: Bool {
        guard let original = originalUser else { return false }
        return name != original.name ||
               email != original.email ||
               birthday != original.birthday ||
               pushEnabled != original.pushEnabled ||
               darkModeEnabled != original.darkModeEnabled
    }
    
    init(userRepository: UserRepository = UserRepositoryImpl()) {
        self.userRepository = userRepository
    }
    
    func loadProfile() async {
        isLoading = true
        defer { isLoading = false }
        
        do {
            let user = try await userRepository.getCurrentUser()
            self.originalUser = user
            self.name = user.name
            self.email = user.email
            self.birthday = user.birthday
            self.pushEnabled = user.pushEnabled
            self.darkModeEnabled = user.darkModeEnabled
        } catch {
            showErrorAlert("Failed to load profile: \(error.localizedDescription)")
        }
    }
    
    func saveProfile() async {
        isLoading = true
        defer { isLoading = false }
        
        guard hasChanges else { return }
        
        let updatedUser = User(
            id: originalUser?.id ?? "",
            name: name,
            email: email,
            birthday: birthday,
            pushEnabled: pushEnabled,
            darkModeEnabled: darkModeEnabled
        )
        
        do {
            try await userRepository.updateUser(updatedUser)
            self.originalUser = updatedUser
            
            // Show success feedback
            let generator = UINotificationFeedbackGenerator()
            generator.notificationOccurred(.success)
        } catch {
            showErrorAlert("Failed to save profile: \(error.localizedDescription)")
        }
    }
    
    private func showErrorAlert(_ message: String) {
        errorMessage = message
        showError = true
    }
}

// MARK: - Model
struct User: Codable, Identifiable {
    let id: String
    var name: String
    var email: String
    var birthday: Date
    var pushEnabled: Bool
    var darkModeEnabled: Bool
}

// MARK: - Repository
protocol UserRepository {
    func getCurrentUser() async throws -> User
    func updateUser(_ user: User) async throws
}

class UserRepositoryImpl: UserRepository {
    private let apiClient: APIClient
    
    init(apiClient: APIClient = .shared) {
        self.apiClient = apiClient
    }
    
    func getCurrentUser() async throws -> User {
        try await apiClient.request(endpoint: .getCurrentUser)
    }
    
    func updateUser(_ user: User) async throws {
        try await apiClient.request(endpoint: .updateUser(user))
    }
}

// MARK: - ViewModel
@HiltViewModel
class UserProfileViewModel @Inject constructor(
    private val userRepository: UserRepository
) : ViewModel() {
    
    private val _uiState = MutableStateFlow(UserProfileUiState())
    val uiState: StateFlow<UserProfileUiState> = _uiState
    
    private var originalUser: User? = null
    
    fun loadProfile() {
        viewModelScope.launch {
            _uiState.value = _uiState.value.copy(isLoading = true)
            
            userRepository.getCurrentUser()
                .onSuccess { user ->
                    originalUser = user
                    _uiState.value = UserProfileUiState(
                        name = user.name,
                        email = user.email,
                        pushEnabled = user.pushEnabled,
                        darkModeEnabled = user.darkModeEnabled,
                        isLoading = false
                    )
                }
                .onFailure { error ->
                    _uiState.value = _uiState.value.copy(
                        isLoading = false,
                        errorMessage = "Failed to load profile: ${error.message}"
                    )
                }
        }
    }
    
    fun saveProfile() {
        viewModelScope.launch {
            _uiState.value = _uiState.value.copy(isLoading = true)
            
            val updatedUser = User(
                id = originalUser?.id ?: "",
                name = _uiState.value.name,
                email = _uiState.value.email,
                pushEnabled = _uiState.value.pushEnabled,
                darkModeEnabled = _uiState.value.darkModeEnabled
            )
            
            userRepository.updateUser(updatedUser)
                .onSuccess {
                    originalUser = updatedUser
                    _uiState.value = _uiState.value.copy(
                        isLoading = false,
                        hasChanges = false
                    )
                }
                .onFailure { error ->
                    _uiState.value = _uiState.value.copy(
                        isLoading = false,
                        errorMessage = "Failed to save profile: ${error.message}"
                    )
                }
        }
    }
    
    fun updateName(name: String) {
        _uiState.value = _uiState.value.copy(
            name = name,
            hasChanges = true
        )
    }
    
    fun updateEmail(email: String) {
        _uiState.value = _uiState.value.copy(
            email = email,
            hasChanges = true
        )
    }
    
    fun togglePush(enabled: Boolean) {
        _uiState.value = _uiState.value.copy(
            pushEnabled = enabled,
            hasChanges = true
        )
    }
    
    fun toggleDarkMode(enabled: Boolean) {
        _uiState.value = _uiState.value.copy(
            darkModeEnabled = enabled,
            hasChanges = true
        )
    }
    
    fun clearError() {
        _uiState.value = _uiState.value.copy(errorMessage = null)
    }
}

    val pushEnabled: Boolean = false,
    val darkModeEnabled: Boolean = false,
    val isLoading: Boolean = false,
    val errorMessage: String? = null,
    val hasChanges: Boolean = false
)
