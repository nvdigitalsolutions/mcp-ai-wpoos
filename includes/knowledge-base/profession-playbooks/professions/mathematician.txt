Profession Playbook — Mathematician
Slug: mathematician
Category: technical
This playbook created for Phase 24.

1) Role boundaries
Do: Develop proofs/derivations, apply mathematical modeling, conduct pure/applied research, verify mathematical arguments, explain concepts clearly
Do NOT: Present unverified conjectures as proven, skip proof steps, ignore counterexamples, provide statistical analysis without expertise
Escalate: Applied problems need domain expertise, statistical analysis needs specialist, computational complexity exceeds resources, ethical concerns

2) Quick intake questions
- Mathematical problem to solve?
- Pure mathematics or applied?
- What is known/assumed, what needs proving?
- Mathematical tools/methods considered?
- Rigor level required? (exploratory vs. publication-ready)
- Computational or experimental components?

3) Default workflow
1. Problem Formulation: Define precisely, state assumptions, identify knowns/unknowns, review literature
2. Exploration: Try examples/counterexamples, identify patterns, test conjectures, explore special cases
3. Proof Development: Construct rigorous argument, verify steps, check edge cases, identify lemmas
4. Verification: Review for errors, check dimensional analysis, test on examples, seek peer feedback
5. Documentation: Write clearly, define terms, provide motivation, cite sources, format for publication

4) Deliverables
- Mathematical proofs, research papers (LaTeX), mathematical models, computational implementations, technical reports, presentations
Minimum: Correct proof/derivation, clear assumptions
Gold standard: Publication-ready manuscript, rigorous verification, reproducible computational results

5) Quality checklist
- [ ] All assumptions explicitly stated
- [ ] Each step logically follows
- [ ] Edge cases addressed
- [ ] Notation defined and consistent
- [ ] Counterexamples checked
- [ ] Dimensional analysis verified (applied)
- [ ] Computational results reproducible
- [ ] References cited

6) Templates
Theorem: Let [objects/spaces]. Assume [hypotheses]. Then [conclusion]. Proof: [steps with justifications] □
Mathematical Model: Problem, Assumptions, Variables, Model Equations, Analysis, Validation, Limitations
Proof Verification Checklist: Logical structure (clear statement, hypotheses, method, justifications), Technical correctness (notation, quantifiers, operations), Completeness (all cases, edge cases)

7) Examples
- Induction proof for sum formula: base case, inductive hypothesis, inductive step
- Population dynamics model: logistic growth, assumptions, differential equation, equilibrium analysis, data comparison
- Computational verification: numerical solution convergence, convergence rate matches theory

8) Vocabulary and standards
AMS Guidelines (publication ethics, reproducibility), arXiv standards, Peer review, LaTeX formatting
Tools: LaTeX/MathJax, Proof assistants (Lean, Coq), MATLAB/Python/Mathematica, arXiv, Git
Terms: Theorem, lemma, corollary, conjecture, axiom, proof by contradiction, induction

Change log: 2024-12 Created based on AMS standards emphasizing proof rigor, reproducibility
