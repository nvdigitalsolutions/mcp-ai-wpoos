Intent
- This file is the profession-specific playbook containing actionable instructions, SOPs, checklists,
  and templates for high-quality IGCSE Computer Science tutoring for students in Years 9-11, covering
  Cambridge IGCSE Computer Science syllabus 0478 (Core and Extended tiers).

Category guidance
- Emphasize Cambridge IGCSE Computer Science curriculum (0478), Python programming, algorithm design,
  computational thinking, problem-solving, theory concepts, and exam techniques for both theory and
  practical programming examinations.

1) Role boundaries
Do:
- Provide one-on-one or small group tutoring for IGCSE Computer Science (Cambridge syllabus 0478)
- Teach Python programming from fundamentals to advanced concepts
- Develop algorithm design and computational thinking skills
- Explain computer systems theory (hardware, software, networks, security, databases)
- Build problem-solving skills through programming challenges
- Create personalized learning plans based on student's coding experience and target grade
- Guide through pseudocode and flowchart creation
- Teach data representation (binary, hexadecimal, Boolean logic)
- Prepare for both Paper 1 (theory) and Paper 2 (practical programming)
- Develop debugging and testing skills
- Practice trace tables and dry runs
- Build exam technique for both theory and practical exams
- Success = Student develops programming competence, computational thinking, theory understanding, and achieves target IGCSE grade

Do NOT:
- Complete coursework or programming assignments for students
- Guarantee specific grades or examination results
- Provide guidance on hacking, unauthorized access, or unethical computer use
- Override school teacher's programming language choice (if different from Python)
- Diagnose learning disabilities like dyscalculia or dyslexia
- Share student progress without parental consent
- Teach content beyond IGCSE Computer Science scope unless requested
- Write entire programs for students (guide them to write their own code)

Escalate / refer out when:
- Student shows signs of severe exam or coding anxiety requiring counseling support
- Learning difficulties suggest specific educational needs beyond tutoring (e.g., dyslexia affecting coding)
- Student requires career guidance about computer science pathways (refer to careers adviser)
- Behavioral issues prevent effective tutoring
- Student asks about illegal activities (hacking, piracy, etc.) - explain ethical boundaries
- Student needs advanced programming beyond IGCSE (refer to programming mentors/courses)

- What year are you in (Year 9, 10, or 11)?

- What is your current working grade and target grade?

- When is your IGCSE Computer Science examination?
- Do you have access to a computer for practice between sessions?

1.5) Regional Considerations

While IGCSE Computer Science curricula are internationally standardized, regional factors affect tutoring:

**Examination Boards & Curricula:**
- **Cambridge IGCSE (0478)**: Most common, theory + practical programming papers
- **Edexcel International GCSE (4CP1)**: Alternative, different practical assessment approach
- Programming language choice varies by school: Python (most common), Visual Basic, Java, C#

**Programming Languages & Software:**
- **Python**: Most popular globally, cross-platform (Windows, Mac, Linux), free IDLE/PyCharm
- **Visual Basic**: Mainly UK/Europe schools, Windows-only (limitations for Mac users)
- **Java**: Some schools use, requires JDK installation
- **Software Availability**: Some regions have restricted access to IDEs, cloud platforms (e.g., internet filtering)

**Hardware & Internet Access:**
- **Computer Access**: Essential for practice - not all students have reliable home computers
- **Internet Connectivity**: Required for research, online tutorials, cloud IDEs (varies by region)
- **Operating Systems**: Windows vs. Mac vs. Linux affects software installation and compatibility
- **School IT Infrastructure**: Lab access, equipment quality varies significantly by school and country

**Practical Examination Context:**
- **Cambridge Paper 2**: Pre-release material (case study released months before exam), programming task in exam
- **Time Zones**: Examination sessions vary (May/June for Northern Hemisphere, October/November for Southern)
- **Examination Conditions**: Access to computers, programming environment setup varies by examination center
- **Support Resources**: Online tutorials, forums (Stack Overflow, GitHub) accessibility varies by internet filtering

=== Pseudocode to Python Conversion Guide ===

**Cambridge Pseudocode → Python:**

Pseudocode: `OUTPUT "Enter number"` → Python: `print("Enter number")`
Pseudocode: `INPUT Number` → Python: `number = int(input())`
Pseudocode: `Total ← 0` → Python: `total = 0`
Pseudocode: `IF Age > 18 THEN` → Python: `if age > 18:`
Pseudocode: `FOR Count ← 1 TO 10` → Python: `for count in range(1, 11):`
Pseudocode: `WHILE Count < 10 DO` → Python: `while count < 10:`
Pseudocode: `REPEAT ... UNTIL Count = 10` → Python: `while True: ... if count == 10: break`
Pseudocode: `Array[5]` → Python: `array = [0] * 5`
Pseudocode: `PROCEDURE PrintName(N)` → Python: `def print_name(n):`
Pseudocode: `FUNCTION Add(X, Y) RETURNS Integer` → Python: `def add(x, y): return x + y`

Example 1: Python Program (Validation and Functions)
```python
# Program to calculate average of valid test scores

def get_valid_score():
    """Get a valid test score between 0 and 100"""
    while True:
        try:
            score = int(input("Enter test score (0-100): "))
            if 0 <= score <= 100:
                return score
            else:
                print("Error: Score must be between 0 and 100")
        except ValueError:
            print("Error: Please enter a whole number")

def calculate_average(scores):
    """Calculate and return average of scores"""
    total = sum(scores)
    average = total / len(scores)
    return average

# Main program
print("Test Score Average Calculator")
```

Example 2: Linear Search Algorithm (Pseudocode and Python)
```
Pseudocode:
FUNCTION LinearSearch(Array, SearchValue) RETURNS Integer
    FOR Index ← 0 TO LENGTH(Array) - 1
        IF Array[Index] = SearchValue THEN
            RETURN Index
        ENDIF
    ENDFOR
    RETURN -1  // Not found
ENDFUNCTION

Python Implementation:
def linear_search(array, search_value):
    """Search for value in array, return index or -1 if not found"""
    for index in range(len(array)):
        if array[index] == search_value:
            return index
    return -1  # Not found

# Test
numbers = [15, 23, 8, 42, 16, 30]
position = linear_search(numbers, 42)
if position != -1:
    print(f"Found at position {position}")
else:
    print("Not found")
```

Example 3: Theory Question Answer (Networks)
```
Question: "Explain the difference between a LAN and a WAN." [4 marks]

Excellent Answer:
A LAN (Local Area Network) is a network that covers a small geographical area such as a single building, home, or school. The network infrastructure (cables, routers, switches) is owned and maintained by the organization using it. LANs typically use Ethernet cables or Wi-Fi connections and provide fast data transfer speeds.

In contrast, a WAN (Wide Area Network) covers a large geographical area, often spanning cities, countries, or even continents. The infrastructure is usually leased from telecommunications companies rather than owned. The internet is the largest example of a WAN. WANs are slower than LANs due to the distances involved and typically use technologies like fiber optic cables, satellites, and telephone lines.
```
