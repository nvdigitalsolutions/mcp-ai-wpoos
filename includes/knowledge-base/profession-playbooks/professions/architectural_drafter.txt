Profession Playbook — Architectural Drafter
Slug: architectural_drafter
Category: technical
Includes: global.txt + categories/technical.txt + this file

Intent
- This file is the profession-specific playbook containing actionable instructions, SOPs, checklists,
  and templates for high-quality architectural drawing production and construction documentation.

Category guidance
- Emphasize requirements, correctness, code compliance, coordination, and clear documentation standards.

1) Role boundaries
Do:
- Create architectural construction documents using AutoCAD, Revit, or ArchiCAD
- Prepare floor plans, elevations, sections, and building details
- Develop door, window, and finish schedules
- Coordinate with engineers and consultants (structural, MEP, civil)
- Apply building codes, zoning regulations, and accessibility standards
- Produce permit submission drawings and construction documents
- Maintain drawing standards and template libraries
- Revise drawings based on architect's redlines and design changes
- Success = Accurate, code-compliant construction documents ready for permitting and bidding

Do NOT:
- Make design decisions without architect's direction
- Seal or stamp drawings (requires licensed architect)
- Approve code interpretations or variances without architect review
- Modify structural or MEP elements without consultant coordination
- Change critical dimensions affecting building code compliance
- Issue construction documents without architect's final review

Escalate / refer out when:
- Building code interpretations require professional judgment
- Design conflicts between disciplines need resolution
- Structural or MEP coordination issues arise
- Accessibility compliance questions require clarification
- Zoning or permit requirements are unclear
- Project involves historic preservation or landmark status

2) Quick intake questions
Ask 3–8 questions that materially affect the answer:
- What project phase is this? (Schematic Design, Design Development, Construction Documents)
- What building type and occupancy? (Residential, commercial, mixed-use)
- What jurisdiction and building codes apply? (IBC edition, state/local amendments)
- What is the project size and complexity? (Square footage, number of floors)
- What deliverable format is required? (CAD, Revit, PDF for permits)
- Are consultants coordinated? (Structural, MEP, civil drawings available?)
- What sheet organization is required? (A-series, discipline codes)
- What is the delivery timeline and review schedule?

3) Default workflow
Use standard architectural documentation workflow:

1. Project Setup and Standards
   - Review architect's schematic design or design development drawings
   - Set up project template with company/office standards
   - Establish drawing sheet organization (A-series: A0 Index, A1 Site, A2 Plans, A3 Elevations, etc.)
   - Configure layers, line weights, text styles per office standards
   - Set up annotation styles and dimension standards
   - Create project-specific title blocks with required information
   - Establish file naming and organization conventions

2. Floor Plan Development
   - Create base floor plan from design sketches or previous phase
   - Define wall types with proper thickness (structural, partitions)
   - Locate all door and window openings with accurate dimensions
   - Add room names and numbers
   - Dimension grid lines, column centers, and major spaces
   - Dimension to face of stud/finished face as appropriate
   - Show floor materials and transitions
   - Indicate ceiling heights if varied
   - Add wall types and assembly notes
   - Coordinate with structural grid and column locations

3. Reflected Ceiling Plans (RCP)
   - Create RCP showing ceiling grid layout
   - Indicate ceiling heights and soffits
   - Show light fixture locations and types (coordinate with electrical)
   - Show diffusers, grilles, and registers (coordinate with mechanical)
   - Add sprinkler head locations (coordinate with fire protection)
   - Include ceiling materials and transitions
   - Note access panels for MEP equipment

4. Exterior Elevations
   - Develop all building elevations (North, South, East, West)
   - Show accurate building height and floor-to-floor heights
   - Indicate all exterior materials with hatch patterns and notes
   - Show window and door types (match schedules)
   - Add finish grade lines and floor levels
   - Dimension key heights and offsets
   - Include material notes and specifications
   - Show roof slopes, parapets, and architectural features

5. Building Sections
   - Create minimum 2 building sections showing key spaces
   - Show floor-to-floor heights and roof structure
   - Indicate ceiling heights and plenum spaces
   - Show wall assemblies and foundation details
   - Coordinate with structural sections
   - Add key dimensions and level datums
   - Reference detail callouts
   - Show insulation and moisture barriers

6. Wall Sections and Details
   - Create enlarged wall sections at 3/4" or 1 1/2" scale
   - Show foundation to roof assembly
   - Detail connections and transitions
   - Include material specifications
   - Show flashing, sealants, and weatherproofing
   - Reference applicable details
   - Coordinate with structural and envelope consultants

7. Enlarged Plans and Details
   - Develop enlarged plans for stairs, restrooms, elevator lobbies
   - Detail millwork, casework, and built-in elements
   - Create door and window jamb details
   - Show accessibility requirements (grab bars, clearances, etc.)
   - Detail special conditions and connections
   - Scale appropriately (1/2", 3/4", 1 1/2", 3" = 1'-0")

8. Schedules
   - **Door Schedule**: Door number, size, material, frame type, hardware set, fire rating, notes
   - **Window Schedule**: Window number, size, type, glazing, frame material, U-value
   - **Finish Schedule**: Room-by-room floor, base, walls, ceiling finishes
   - **Room Data Sheet**: Area, occupancy, finishes, special requirements

9. Code Compliance Documentation
   - Prepare code analysis summary (occupancy, construction type, height/area)
   - Create egress plans showing exit paths, travel distances, door swings
   - Show fire-rated assemblies and separation walls
   - Document accessibility compliance (ramps, elevators, toilet rooms)
   - Include energy code compliance notes (if required)

10. Coordination and Quality Control
    - Coordinate dimensions and information across all sheets
    - Check detail callouts match detail sheets
    - Verify door/window numbers match schedules
    - Cross-reference consultant drawings (structural, MEP)
    - Review for code compliance
    - Check for completeness and constructability
    - Submit to architect for review before issue

11. Permit Submission Preparation
    - Organize complete drawing set per jurisdiction requirements
    - Include all required sheets and consultants' drawings
    - Add permit title sheet with project data and code summary
    - Ensure drawings meet jurisdiction's submission format
    - Prepare PDF set with proper sheet order
    - Coordinate with architect for seal/stamp

4) Deliverables
List the artifacts commonly produced:

**Construction Document Set (CD Phase):**
- Cover Sheet / Index (A0): Project data, drawing index, abbreviations, symbols
- Site Plan (A1): Building location, property lines, setbacks, parking
- Floor Plans (A2 series): All levels with dimensions, room names, door/window numbers
- Reflected Ceiling Plans (A4 series): Ceiling layouts coordinated with MEP
- Roof Plan (A5): Roof geometry, drainage, equipment locations
- Exterior Elevations (A3 series): All sides with materials and heights
- Building Sections (A5 series): Key sections through building
- Wall Sections (A6 series): Enlarged sections showing assembly details
- Enlarged Plans (A7 series): Stairs, restrooms, special spaces
- Details (A8 series): Construction details at various scales
- Schedules (A9 series): Door, window, finish, room data schedules

**Schematic Design Deliverables:**
- Conceptual floor plans (1/16" or 1/8" scale)
- Exterior elevations (schematic level)
- Key building sections
- Design renderings (if required)

**Design Development Deliverables:**
- Floor plans (1/8" or 1/4" scale) with dimensions
- RCPs showing preliminary MEP coordination
- Elevations with material indications
- Key sections and enlarged plans
- Outline specifications
- Door and window schedules

**Minimum viable deliverable**: 
Floor plans, elevations, and basic sections sufficient for design review and preliminary permitting.

**Gold standard deliverable**: 
Complete coordinated construction document set with all details, schedules, code documentation, fully coordinated with consultants, ready for permit submission and construction bidding.

5) Quality checklist
Create architectural drafting-specific QA gates:

**Floor Plan Check:**
- [ ] All walls dimensioned or located relative to grid
- [ ] Room names and numbers complete and consistent
- [ ] Door and window numbers match schedules
- [ ] Wall types indicated and match wall legend
- [ ] Grid lines labeled and coordinated across floors
- [ ] Stair and elevator locations match across floors
- [ ] Accessible routes shown and dimensioned
- [ ] Floor material indications shown

**Elevation Check:**
- [ ] All elevations shown (typically N, S, E, W)
- [ ] Building heights and floor levels dimensioned
- [ ] Materials indicated with notes and patterns
- [ ] Window and door types match schedules
- [ ] Roof slopes and drainage indicated
- [ ] Grade lines shown
- [ ] Scale appropriate for detail level

**Section Check:**
- [ ] Floor-to-floor heights shown and dimensioned
- [ ] Ceiling heights indicated
- [ ] Roof assembly and structure coordinated with structural drawings
- [ ] Foundation shown and coordinated with structural
- [ ] Detail callouts reference correct detail sheets
- [ ] Level datums consistent across all sections

**Detail Check:**
- [ ] Details drawn at appropriate scale (1/2", 3/4", 1 1/2", 3")
- [ ] All materials labeled
- [ ] Connections and fasteners shown
- [ ] Referenced on plan/section drawings
- [ ] Notes complete and specific
- [ ] Constructible and coordinated with specifications

**Schedule Check:**
- [ ] Door schedule complete with all required information
- [ ] Door numbers match floor plans
- [ ] Window schedule includes all windows on elevations
- [ ] Finish schedule covers all rooms
- [ ] Fire ratings shown where required
- [ ] Hardware sets assigned correctly

**Code Compliance Check:**
- [ ] Occupancy classification documented
- [ ] Construction type appropriate for height/area
- [ ] Egress widths and travel distances meet code
- [ ] Accessible paths of travel provided
- [ ] Fire-rated assemblies indicated
- [ ] Required separations shown
- [ ] Toilet room layouts meet accessibility requirements

**Coordination Check:**
- [ ] Structural grid matches structural drawings
- [ ] Ceiling heights accommodate MEP systems
- [ ] Equipment locations coordinated with MEP drawings
- [ ] Door swings don't conflict with furniture or egress
- [ ] Details coordinate across disciplines
- [ ] Sheet references are accurate (no broken callouts)

**Drawing Set Check:**
- [ ] Sheet index matches actual sheets in set
- [ ] Title blocks complete on all sheets
- [ ] Revision indicators current
- [ ] North arrows consistent
- [ ] Scales indicated on all drawings
- [ ] General notes included where appropriate
- [ ] Drawing set organized per standards (A-series)

8) Vocabulary and standards

**Key Terms:**
- **AFF**: Above Finished Floor - measurement reference
- **FD**: Floor Drain
- **GWB**: Gypsum Wall Board (drywall)
- **ACT**: Acoustic Ceiling Tile
- **VCT**: Vinyl Composition Tile
- **RCP**: Reflected Ceiling Plan
- **T.O.**: Top Of (T.O. Wall, T.O. Parapet, etc.)
- **FFE**: Furniture, Fixtures, and Equipment
- **CMU**: Concrete Masonry Unit (concrete block)
- **Datum**: Reference elevation (typically first floor = 0'-0")
- **Egress**: Exit path from building
- **Fire-Rating**: Time rating for fire resistance (e.g., 1-hour, 2-hour)
- **A-Series Sheets**: Architectural drawing organization (A1, A2, A3, etc.)

**Standards & Codes (2024):**
- **IBC 2024 (International Building Code)**: Primary building code
- **IRC 2024 (International Residential Code)**: 1-2 family dwellings
- **IECC 2024 (International Energy Conservation Code)**: Energy efficiency
- **ICC A117.1-2017**: Accessibility standard (referenced by IBC)
- **ADA Standards (2010)**: Federal accessibility requirements
- **NFPA 101 (Life Safety Code)**: Alternative egress code
- **NFPA 13**: Automatic sprinkler systems
- **NFPA 80**: Fire doors and other opening protectives
- **ASTM E84**: Surface burning characteristics (flame spread)
- **CSI MasterFormat**: Specification organization (Divisions 00-16 or 00-50)

**Common Software:**
- **AutoCAD**: 2D drafting standard
- **Revit**: BIM/3D architectural modeling and documentation
- **ArchiCAD**: BIM alternative to Revit
- **SketchUp**: 3D conceptual modeling
- **Bluebeam Revu**: PDF markup and coordination
- **Navisworks**: Model coordination and clash detection

**Measurement Conventions:**
- Dimensions typically in feet and inches (e.g., 10'-6")
- Small dimensions in inches (e.g., 3")
- Scales: 1/8" = 1'-0" (plans), 1/4" = 1'-0" (enlarged plans), 3/4" = 1'-0" (details)
