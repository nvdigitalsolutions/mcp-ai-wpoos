## Research Methodology

### Step 1: Identify Authoritative Sources

For each profession, research from:

**Primary Sources (Professional Organizations)**:
- Professional associations (e.g., AMA, IEEE, ABA, AICPA)
- Licensing boards and regulatory bodies
- Industry standards organizations (ISO, ANSI, NIST)

**Secondary Sources (Best Practices)**:
- Industry publications and journals
- Government agency guidance (OSHA, CDC, FDA, FTC)
- Academic research and white papers
- Leading practitioners and thought leaders

**Search Strategy**:
```
[profession] best practices workflows standards 2024
[profession] professional standards guidelines current
[profession] industry best practices [year]
[association name] standards 2024
```

### Step 2: Extract Key Information

Gather these elements for each profession:

1. **Professional Standards** (2-3 current standards/frameworks)
2. **Core Competencies** (5-8 key skills/responsibilities)
3. **Typical Workflows** (3-5 step process)
4. **Common Deliverables** (5-10 work products)
5. **Quality Criteria** (4-6 checklist categories)
6. **Tools & Technologies** (5-10 commonly used)
7. **Ethical Boundaries** (3-5 "do not" items)
8. **Escalation Triggers** (4-6 scenarios)

### Step 3: Structure Content

Follow this 8-section template (see Section: Template Structure below).

## Batch Completion Process

### Recommended Workflow

1. **Select Profession Batch** (10-20 similar professions)
2. **Conduct Research Session** (1-2 hours)
   - Research all professions in batch
   - Identify common patterns and unique elements
   - Note authoritative sources for each
3. **Create Base Template** (30 min)
   - Adapt exemplar template for profession type
   - Fill in category-wide commonalities
4. **Complete Individual Playbooks** (20-30 min each)
   - Customize base template for each profession
   - Add profession-specific details
   - Include real examples and use cases
5. **Quality Review** (10 min each)
   - Verify all 8 sections complete
   - Check for accuracy and clarity
   - Ensure authoritative sources cited
6. **Commit Batch** (5 min)
   - Git commit with descriptive message
   - Update progress tracking

## Quality Standards

Every completed playbook must:

- [x] Include all 8 sections with substantive content
- [x] Cite at least 2-3 authoritative sources (2024 preferred)
- [x] Provide 2-5 paste-ready templates
- [x] Include 3 realistic examples
- [x] Define clear success criteria
- [x] List profession-specific tools and standards
- [x] Be 12-20KB (approximately 400-550 lines)
- [x] Use professional, actionable language
- [x] Be free of TODOs and placeholders

## Common Pitfalls to Avoid

1. **Too Generic**: Don't just adapt exemplar verbatim - add profession-specific details
2. **Outdated Information**: Always use 2023-2024 sources when available
3. **Missing Compliance**: Include relevant regulations, licenses, certifications
4. **Weak Examples**: Provide realistic, complete examples, not fragments
5. **Unclear Boundaries**: Be explicit about what is/isn't in scope
6. **Tool Overload**: Focus on widely-used, current tools
7. **Jargon Without Explanation**: Define technical terms in Vocabulary section
8. **Missing Escalation**: Always define when to refer to specialists
