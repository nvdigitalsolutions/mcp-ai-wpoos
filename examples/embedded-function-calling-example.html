🔧 WebLLM Function Calling Example

This example demonstrates how to use function calling with the embedded WebLLM client. Function calling allows the AI model to call external functions/tools during conversation.

Prerequisites

  • Modern browser with WebGPU support (Chrome 113+, Edge 113+, or Safari 18+)
  • At least 4GB RAM for smaller models
  • Fast internet connection for initial model download (~1-4GB)
  • Function calling requires models like Hermes-2-Pro or similar instruction-tuned models

Defined Tools/Functions

get_current_weather

Get the current weather in a given location

{ "name": "get_current_weather", "description": "Get the current weather in a given location", "parameters": { "type": "object", "properties": { "location": { "type": "string", "description": "The city and state, e.g. San Francisco, CA" }, "unit": { "type": "string", "enum": ["celsius", "fahrenheit"] } }, "required": ["location"] } }

Chat Messages

How It Works

  1. Define tools/functions with JSON schema (see above)
  2. Send a chat request with tools parameter
  3. Model may respond with tool_calls if it needs to call a function
  4. Execute the function with provided arguments
  5. Send function results back to model as tool role messages
  6. Model uses results to generate final response
