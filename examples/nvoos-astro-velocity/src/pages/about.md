# About

The NV Store is an **NV-authored, MIT-licensed headless storefront** built
with Astro (Proposal 092). It renders server-side for search engines and
human visitors alike, hydrates only small interactive islands, and binds to
one stable commerce contract.

The storefront is backend-agnostic by construction: it speaks the
Payload-shaped REST envelope served by the NV commerce contract, whether that
contract is served by WordPress today or by another backend tomorrow.
