What's Happening?

When you click "Load into chat", the JavaScript simulates the window.wpMcpAiLoadSession() API call. In the actual WordPress plugin, this would:

  • Fetch the complete session data from the REST API
  • Find the target chat widget using the configured selector
  • Clear the current conversation in the chat widget
  • Load all historical messages in sequence
  • Update the session key for conversation continuation
  • Save the loaded conversation to localStorage
