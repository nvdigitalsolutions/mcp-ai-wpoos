## Key Technical Differences

### Text Domain Transformation

**Standard Builds:**
```php
__( 'Text', 'mcp-ai-wpoos' )
```

**WordPress.org Builds:**
```php
__( 'Text', 'nvdigital-open-operator-system-oos' )
```

**Why:** WordPress.org requires text domain to match plugin slug.

### CDN Feature Exclusions

**Excluded from WordPress.org:**
- `includes/class-wp-mcp-ai-langchain-enqueue.php`
- `includes/class-wp-mcp-ai-transformers-enqueue.php`
- `includes/class-wp-mcp-ai-webworker-enqueue.php`
- `assets/js/langchain-*.js`
- `assets/js/transformers-*.js`
- `assets/js/web-worker-*.js`

**Why:** These files load external JavaScript from jsDelivr CDN at runtime, which violates WordPress.org policy.

**Impact:** WordPress.org users lose:
- LangChain.js orchestration (advanced feature, opt-in)
- Transformers.js browser AI (advanced feature, opt-in)
- Web Workers (performance feature, opt-in)

**Note:** These are ALL optional, opt-in, Pro features. Base functionality works perfectly without them.

### File Size Comparison

```
WordPress.org Base:      7.4 MB  (smallest - optimized)
Standard Base:           8.5 MB  (includes CDN features)
Commercial Pro:         18.0 MB  (optimized Pro)
Standard Pro:           19.0 MB  (includes docs)
Combined:               20.0 MB  (everything)
Core:                    0.036 MB (minimal)
```

**Size Savings:** WordPress.org is 1.1MB smaller due to:
- CDN features excluded (92KB)
- Documentation excluded
- Dev files excluded
- Build artifacts excluded
