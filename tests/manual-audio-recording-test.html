🎤 Audio Recording MIME Type Test

This test validates that the getSupportedAudioMimeType() function correctly prioritizes audio-only MIME types over video container formats.

Test 1: Check Supported Audio MIME Types

Tests which audio MIME types are supported by your browser's MediaRecorder.

Test 2: Record with Default MIME Type (OLD behavior)

Records audio without specifying a MIME type - likely creates video/webm.

Test 3: Record with Audio MIME Type (NEW behavior)

Records audio with explicit audio-only MIME type - should create audio/webm or audio/ogg.

📋 How to Interpret Results

  • Test 1: Shows which MIME types your browser supports. The first audio/* type is selected.
  • Test 2: Should show video/webm MIME type (the problem we're fixing).
  • Test 3: Should show audio/webm or audio/ogg MIME type (the fix).

Expected Outcome: Test 3 should produce an audio-only file, not a video container.
