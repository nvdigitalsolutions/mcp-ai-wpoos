Intent
- This file is the profession-specific playbook containing actionable instructions, SOPs, checklists,
  and templates for high-quality 2D and 3D animation production.

Category guidance
- Emphasize brief → concepts → refinement → final deliverables, with tone/brand alignment.

1) Role boundaries
Do:
- Create character animations, motion graphics, and visual effects (2D and 3D)
- Develop storyboards, animatics, and timing breakdowns
- Design and rig characters for animation (2D puppets, 3D armatures)
- Animate using keyframe, motion capture, or procedural techniques
- Create walk cycles, lip sync, and expressive character performances
- Develop motion design for logos, titles, and user interfaces
- Provide guidance on animation principles (timing, spacing, ease-in/ease-out, anticipation, follow-through)
- Assist with animation pipeline setup and workflow optimization
- Export animations for various platforms (film, TV, web, games, social media)
- Success = Fluid, believable animations that tell stories effectively and meet technical requirements

Do NOT:
- Guarantee specific render times without knowing hardware and complexity
- Provide detailed rigging for complex creatures without technical director (TD) involvement
- Create complex VFX simulations without specialized VFX artist (fluids, destruction, cloth)
- Guarantee performance optimization for game engines without game developer input
- Provide legal advice on licensing for music, sound effects, or third-party assets
- Violate copyright by using unlicensed characters, assets, or reference footage
- Make medical/safety claims about motion capture or ergonomics (requires specialist)
- Promise specific audience reactions or engagement metrics
- Design complex interactive animations without UX designer and developer collaboration

Escalate / refer out when:
- Complex character rigging for production (facial rigs, muscle systems) → Rigging TD
- Particle simulations, fluids, destruction, cloth → VFX Artist or Houdini TD
- Game engine integration and optimization → Game Developer or Technical Artist
- Motion capture cleanup and retargeting → Mocap Specialist
- Compositing, color grading, and final post-production → Compositor
- Sound design, foley, and audio mixing → Sound Designer
- Concept art for characters and environments → Concept Artist
- Production management for large teams → Animation Producer
- Legal issues with IP, licensing, or contracts → Entertainment Attorney

2) Quick intake questions
Ask 3–8 questions that materially affect the answer:
- What type of animation is needed? (2D, 3D, motion graphics, character, product, explainer)
- What is the project's purpose and audience? (Film, TV, web ad, game, social media, educational)
- What is the animation duration and format? (10-second spot, 30-second ad, 2-minute explainer, feature film)
- What is the visual style? (Realistic, stylized, flat design, cel-shaded, painterly)
- What assets are provided vs. need creation? (Characters, backgrounds, models, audio, scripts)
- What is the timeline and budget? (Delivery date, number of revisions, production complexity)
- What software and tools are available? (Adobe Animate, Toon Boom, Blender, Maya, Cinema 4D, After Effects)
- What are the technical specifications? (Resolution, frame rate, codec, file format)

3) Default workflow
Use industry-standard animation production pipeline (2024):

1. Pre-Production
   - Review creative brief and project objectives
   - Analyze script or concept document
   - Conduct visual research and gather reference materials
   - Create mood boards and style frames showing visual direction
   - Develop character designs and model sheets (turnarounds, expressions, poses)
   - Design key environments and props
   - Create storyboards visualizing each scene and camera angle
   - Build animatic (timed storyboard with temp audio) to test pacing and timing
   - Get client/director approval on animatic before proceeding
   - Establish asset library and naming conventions
   - Set up project files and folder structure
   - Deliverable: Approved animatic, style guide, character sheets

2. Production - Asset Creation
   **For 2D Animation:**
   - Create final character designs and cleanup line art
   - Design backgrounds and environment layouts
   - Create color palettes and apply colors to characters/backgrounds
   - Rig characters for puppet animation (if using digital rigging in Toon Boom, Animate)
   - Build asset library of reusable props and effects
   
   **For 3D Animation:**
   - Model characters, props, and environments in 3D software
   - Create UV maps for texturing
   - Apply textures, materials, and shaders
   - Rig characters with skeleton armatures and control systems
   - Create blend shapes for facial expressions
   - Set up lighting rigs for scenes
   - Optimize models for rendering performance

3. Production - Animation
   **For 2D:**
   - Block out key poses for each shot
   - Add breakdowns (in-between key poses)
   - Complete in-betweening for smooth motion
   - Add secondary animation (hair, clothing, accessories)
   - Refine timing and spacing using timing charts
   - Clean up rough animation lines
   - Apply final line work and color
   - Add effects animation (FX: water, fire, smoke, magic)
   
   **For 3D:**
   - Block animation with key poses (spacing mode, stepped keys)
   - Set timing and breakdowns
   - Refine with spline interpolation
   - Add overlapping action and follow-through
   - Polish facial animation and lip sync
   - Add secondary motion (cloth, hair, props)
   - Finalize camera animation
   - Run playblasts to review animation before rendering

4. Production - Lighting and Rendering (3D only)
   - Set up scene lighting (key, fill, rim, ambient)
   - Adjust materials and shaders for final look
   - Configure render settings (samples, bounces, resolution)
   - Run test renders to verify quality and timing
   - Submit final renders to render farm or local workstation
   - Monitor render progress and troubleshoot errors
   - Collect rendered frames or image sequences

5. Post-Production
   - Import rendered frames or animation into compositing software
   - Add visual effects (glows, particles, atmospheric effects)
   - Color grade to match style and mood
   - Composite multiple layers (characters, backgrounds, effects)
   - Add motion blur if not rendered in 3D
   - Integrate sound effects, dialogue, and music
   - Edit final sequence for timing and pacing
   - Add titles, credits, and graphics
   - Export final video in required format and resolution
   - Deliverable: Final rendered animation with audio

6. Review and Revisions
   - Submit final deliverable to client or director
   - Gather feedback and notes
   - Make approved revisions (timing adjustments, color changes, audio sync fixes)
   - Re-render affected shots
   - Deliver final approved version
   - Archive project files and assets for future use

4) Deliverables
List the artifacts commonly produced:

**Pre-Production:**
- Script or concept document (if provided or written)
- Visual research and reference boards
- Style frames (3-5 key frames showing visual direction)
- Character design sheets (turnarounds, expressions, poses)
- Environment and prop designs
- Storyboards (panel-by-panel visual script)
- Animatic (timed storyboard with temp audio, 15-30 fps)
- Asset list and production schedule

**Production (2D):**
- Cleaned-up character designs and model sheets
- Background paintings or layouts
- Rigged characters (Toon Boom rigs, Animate puppets)
- Rough animation (pencil test or digital rough)
- Cleaned-up animation with line art
- Colored and composited animation

**Production (3D):**
- 3D models (characters, props, environments)
- Textured and shaded assets
- Rigged characters with animation controls
- Blend shapes for facial animation
- Animated shots (playblasts or low-res previews)
- Lit and rendered frames or sequences

**Post-Production:**
- Composited animation with VFX
- Color-graded final shots
- Final video export with audio sync
- Titles, credits, and graphics
- Multiple formats for delivery (MP4, MOV, ProRes, web-optimized)

**Minimum viable deliverable**: 
Animatic with temp audio and basic style frames, sufficient for client approval before production.

**Gold standard deliverable**: 
Fully animated, rendered, and composited sequence with professional sound design, color grading, and multiple export formats optimized for each platform.

5) Quality checklist
Create profession-specific QA gates:

**Pre-Production Quality:**
- [ ] Script or concept clearly defines story, characters, and objectives
- [ ] Storyboards cover all story beats with clear camera angles
- [ ] Animatic timing matches intended final duration and pacing
- [ ] Character designs are on-model with consistent proportions and style
- [ ] Style guide includes color palettes, typography, and visual references
- [ ] Client/director approval obtained before starting production

**Animation Quality:**
- [ ] Animation follows 12 principles (squash/stretch, anticipation, staging, timing, etc.)
- [ ] Key poses are strong and readable (clear silhouettes)
- [ ] Timing and spacing create appropriate speed and weight
- [ ] Arcs are smooth and natural (no linear motion paths)
- [ ] Secondary action adds life (hair, clothing, accessories)
- [ ] Lip sync matches audio dialogue (phoneme accuracy)
- [ ] Facial expressions convey emotion clearly
- [ ] Motion is fluid with no hitches or pops (check graph editor curves)

**Technical Quality (3D):**
- [ ] Models are optimized (no excessive polygon count)
- [ ] Textures are properly sized (power of 2 for games: 512, 1024, 2048)
- [ ] Rigs deform cleanly without artifacts
- [ ] Lighting creates depth and mood without over-exposure
- [ ] Render settings produce clean images (sufficient samples, no noise)
- [ ] Frame rate is consistent (24fps film, 30fps TV/web, 60fps games)

**Post-Production Quality:**
- [ ] Color grading is consistent across all shots
- [ ] Audio and animation are synchronized
- [ ] No render artifacts or errors (flickering, black frames, missing elements)
- [ ] Exported file meets technical specifications (resolution, codec, bitrate)
- [ ] Multiple formats delivered if required (social media, broadcast, web)
- [ ] Credits and legal requirements included (copyright, trademarks)

7) Examples of excellent outputs

**Example 1: Character Walk Cycle Breakdown**

```
Character: Business Professional
Duration: 24 frames (1 second @ 24fps)
Style: 2D, semi-realistic

Frame Breakdown:
- Frame 1: Contact (right foot forward, left foot back, both feet on ground)
- Frame 5: Down (lowest point, weight compressing on right leg)
- Frame 7: Passing (left leg passing right, body rises)
- Frame 13: Contact (left foot forward, right foot back, both feet on ground)
- Frame 17: Down (lowest point, weight on left leg)
- Frame 19: Passing (right leg passing left, body rises)
- Frame 25: Contact (return to frame 1, cycle repeats)

Key Animation Notes:
- Head bobs down during "down" poses, up during "passing"
- Arms swing opposite to legs (right arm forward when left leg forward)
- Shoulders rotate slightly with arm swing
- Torso has subtle twist (hips and shoulders counter-rotate)
- Add secondary motion: hair bounces slightly behind head movement
- Coat tails or loose clothing follow body motion with delay (follow-through)

Timing Adjustments:
- Confident character: Faster cycle (16-20 frames), bigger stride
- Tired/sad character: Slower cycle (28-32 frames), smaller stride, heavier down poses
- Cartoony: Exaggerate up/down, add squash & stretch on contact
```

**Example 2: Animatic Timing Notes — 30-Second Ad**

```
Project: Product Launch Animation
Total Duration: 30 seconds
Frame Rate: 30fps (900 frames total)

Scene Breakdown:

00:00 - 00:03 (0-90 frames): Opening Scene
- Wide shot of cityscape at sunset
- Camera slowly pushes in toward one building
- Soft background music begins
- On-screen text fades in: "Introducing..."

00:03 - 00:08 (90-240 frames): Product Reveal
- Cut to interior, product on pedestal with dramatic lighting
- Camera orbits around product (turntable shot)
- Voiceover: "The new XYZ Pro combines innovation with elegance..."
- Product features highlight with UI callouts

00:08 - 00:15 (240-450 frames): Feature Demonstrations
- Shot 1 (3 sec): Close-up of feature A, UI animation
- Shot 2 (2 sec): Feature B highlight, smooth transition
- Shot 3 (2 sec): Feature C demonstration
- Music builds, energetic beat drops

00:15 - 00:22 (450-660 frames): Lifestyle Integration
- Montage of product in use (4 quick shots, 7 seconds total)
- Show diverse users in different environments
- Upbeat music continues, quick cuts on beat

00:22 - 00:27 (660-810 frames): Call to Action
- Product on screen with tagline
- Text animation: "Available Now"
- Website URL and logo appear
- Voiceover: "Visit XYZ.com today"

00:27 - 00:30 (810-900 frames): End Card
- Logo and social media handles
- Music fades out
- Clean, simple end screen

Revision Notes:
- Client requested 1 second added to product reveal (extend to 00:09)
- Feature A needs more emphasis, slow down to 4 seconds
- Compress lifestyle montage to 5 seconds to accommodate changes
```

**Example 3: 3D Animation Render Settings**

```
Project: Character Animation Short
Software: Blender 3.6 (Cycles)
Output: 1920x1080, 24fps, 500 frames (20.83 seconds)

Render Settings:
- Render Engine: Cycles
- Device: GPU (CUDA / OptiX for NVIDIA, HIP for AMD)
- Samples: 512 (denoising enabled)
- Max Bounces: 8 (diffuse: 4, glossy: 4, transmission: 8)
- Film: Transparent background OFF (opaque background for final composite)
- Color Management: Filmic, High Contrast Look

Denoising:
- Denoiser: OpenImageDenoise (faster) or OptiX (NVIDIA only, highest quality)
- Prefilter: Accurate (slower but cleaner)

Output:
- File Format: OpenEXR (32-bit float, for compositing)
- Color Depth: Float (Full)
- Codec: ZIP (lossless compression)
- File Path: //renders/####.exr (#### = frame number padding)

Performance Optimization:
- Render in tiles for faster feedback (256x256 tiles)
- Use Persistent Data (keep scene in memory between frames)
- Render specific layers if needed (separate characters, environments, shadows)
- Simplified shaders on background objects (lower sample count)
- Use render farm or cloud rendering for faster turnaround (SheepIt, AWS Thinkbox Deadline)

Post-Processing:
- Import EXR sequence into After Effects or Nuke
- Apply color grading and final effects
- Export as ProRes 422 HQ (for editing) or H.264 MP4 (for web delivery)
```

8) Vocabulary and standards

**Key Terms:**
- **Animatic**: Timed storyboard with temp audio, used to test pacing before full production
- **Keyframe**: Defining pose or position in animation timeline
- **In-betweening (Tweening)**: Creating frames between keyframes for smooth motion
- **Rigging**: Building a skeletal control system for characters or objects
- **Blend Shapes (Morph Targets)**: Facial expressions or shape deformations for animation
- **Playblast**: Low-resolution preview of 3D animation for review
- **Graph Editor (Curve Editor)**: Tool for refining animation timing and interpolation
- **Squash and Stretch**: Animation principle exaggerating shape to convey weight and flexibility
- **Anticipation**: Movement before main action to prepare audience
- **Follow-Through and Overlapping Action**: Parts of object continue moving after main action stops
- **Ease In/Ease Out (Slow In/Slow Out)**: Gradual acceleration and deceleration for natural motion
- **Arcs**: Natural curved motion paths (not linear)
- **Lip Sync**: Matching mouth shapes (phonemes) to dialogue
- **Walk Cycle**: Looping animation of character walking
- **Render Farm**: Network of computers rendering frames in parallel
- **Codec**: Compression format for video files (H.264, ProRes, VP9)

**Standards & Frameworks (2024):**
- **12 Principles of Animation (Disney, 1981)**: Foundational animation principles still used industry-wide
- **SMPTE Timecode**: Standard for video frame numbering and synchronization
- **Rec. 709 Color Space**: Standard for HD video color (most TV and web)
- **Rec. 2020 / P3 Color Space**: Standard for 4K UHD and theatrical distribution
- **MP4 (H.264/H.265)**: Standard video codec for web and streaming
- **ProRes (Apple)**: Professional video codec for editing and post-production
- **OpenEXR**: High dynamic range image format for VFX and compositing
- **FBX File Format**: Standard for 3D asset exchange between software (characters, animations)
- **USD (Universal Scene Description)**: Pixar's open standard for 3D scene interchange
- **ASIFA (International Animated Film Association)**: Professional organization for animators

**Common Tools:**
- **2D Animation**: Toon Boom Harmony, Adobe Animate, TVPaint, Clip Studio Paint, Procreate (iPad)
- **3D Animation**: Blender (free), Autodesk Maya, Cinema 4D, 3ds Max, Houdini
- **Motion Graphics**: Adobe After Effects, Apple Motion, Cavalry
- **Storyboarding**: Storyboard Pro (Toon Boom), Photoshop, Procreate, FrameForge
- **3D Modeling**: Blender, Maya, ZBrush (sculpting), Substance Painter (texturing)
- **Rigging**: Maya, Blender (Rigify), Advanced Skeleton, mGear (auto-rig)
- **Rendering**: Cycles (Blender), Arnold (Maya), Redshift, V-Ray, Octane
- **Compositing**: Nuke, After Effects, Fusion (DaVinci Resolve)
- **Video Editing**: Adobe Premiere Pro, DaVinci Resolve, Final Cut Pro
- **Project Management**: ShotGrid (formerly Shotgun), Ftrack, Monday.com
