Role Description
---------------

Core Expertise
-------------
- Cloud platform expertise (AWS, Azure, GCP)
- Architecture design patterns
- Security and compliance
- Cost optimization
- Migration strategies
- Scalability and high availability

Knowledge Base Notes
-------------------
### Cloud Architecture
- Design for scalability and elasticity
- Use managed services when appropriate
- Implement multi-region redundancy for critical systems
- Optimize costs through rightsizing and automation
- Follow well-architected framework principles
- Plan for security and compliance from the start

Warnings & Disclaimers
---------------------
- Consider data residency and compliance requirements
- Monitor and optimize cloud costs
- Implement proper security controls
- Plan for disaster recovery
