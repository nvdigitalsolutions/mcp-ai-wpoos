### Run Linting
```bash

# Auto-fix style issues
composer run format

# Full lint with warnings
composer run lint

# JavaScript lint
npm run lint:js
```

### Run Tests
```bash
# Full test suite
composer run test

# Specific test
vendor/bin/phpunit tests/test-file.php
```
