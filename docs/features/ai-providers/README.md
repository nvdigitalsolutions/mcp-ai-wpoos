# Features — AI Providers

Documentation for each supported AI language-model provider.

## What belongs here

- **deepseek/** — DeepSeek setup and configuration
- **gemini/** — Google Gemini integration, geospatial, image editing
- **huggingface/** — Hugging Face datasets and inference
- **lm-studio/** — Local LM Studio setup, function calling, SSE
- **nvidia/** — NVIDIA NIM setup
- **openai/** — GPT models, Realtime API, Sora, image generation
- Provider-agnostic docs: Baseten, DigitalOcean, OpenRouter

## What doesn't belong here

- Model catalog and specifications → `../../reference/models/`
- Provider settings admin UI → `../../admin-guides/settings/`
- Provider client implementation → `../../developer/`
