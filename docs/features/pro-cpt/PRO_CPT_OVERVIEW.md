# Pro Custom Post Types Overview

**Last Updated:** January 6, 2026  
**Plugin Version:** 1.1.0  
**Feature:** Pro Addon

---

## Overview

The **Pro addon** includes three comprehensive custom post types (CPTs) that extend WordPress content management with AI-powered tools:

1. **Events** - Calendar and event management (5 tools)
2. **Quizzes** - Interactive assessments (9 tools)  
3. **Places** - Location management (7 tools)

**Total: 21 specialized AI tools** for automated content operations.

---

## Events Management

### Tools (5)
- `create_event` - Create calendar events
- `list_events` - Query events by filters
- `update_event` - Modify event details
- `delete_event` - Remove events
- `create_google_calendar_event` - Google Calendar sync

### Use Cases
- Conference scheduling
- Webinar management
- Appointment booking

---

## Quizzes Management

### Tools (9)
- `create_quiz` - Build quizzes
- `list_quizzes` - Browse quizzes
- `update_quiz` - Edit content
- `get_quiz` - Retrieve details
- `submit_quiz_answer` - Record answers
- `get_quiz_results` - View results
- `get_quiz_submissions` - All submissions
- `get_quiz_analytics` - Statistics
- `grade_quiz` - Score submissions

### Features
- Multiple question types
- Automated grading
- Analytics dashboard
- JetEngine CCT integration (optional)

### Use Cases
- Educational assessments
- Training certifications
- Customer surveys
- Lead generation

---

## Places Management

### Tools (7)
- `create_place` - Add locations
- `list_places` - Query places
- `get_place` - Retrieve details
- `update_place` - Modify info
- `delete_place` - Remove places
- `search_and_save_places` - Google Places API
- Location-based queries - Distance/proximity

### Features
- Google Places API integration
- Geocoding and mapping
- Contact management

### Use Cases
- Business directories
- Restaurant listings
- Real estate properties
- Store locators
