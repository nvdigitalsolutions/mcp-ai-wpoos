# Machine Learning Engineer Professional Playbook

## Overview

**Profession:** Machine Learning Engineer  
**Primary Toolkit:** AI & Model Management  
**Recommended Pattern:** Experimentation Pipeline  
**Risk Tolerance:** Standard  
**Team Size:** 4 agents  

## Primary Tools (27 Tools)

### Model Management
- `list_available_models` - Browse models
- `suggest_best_model` - Model recommendations
- `get_model_information` - Model details
- `discover_new_models` - Find new models
- `research_model` - Model research

### AI Operations
- `add_model_config` - Configure models
- `enable_reasoning_mode` - Advanced reasoning
- `validate_reasoning_chain` - Validate logic
- `count_tokens` - Token management

### Data & Embeddings
- `create_text_embeddings` - Generate embeddings
- `batch_embed_content` - Batch processing
- `create_vector_store` - Vector storage
- `manage_vector_store_files` - File management

### Batch Processing
- `create_batch` - Create batch jobs
- `list_batches` - View batches
- `get_batch_status` - Check status
- `monitor_batch` - Monitor progress

## Recommended Pattern: Experimentation Pipeline

Multiple agents try different approaches and select the best result through systematic testing.

## Common Use Cases

1. **Model Selection & Benchmarking** - Compare multiple models
2. **Hyperparameter Tuning** - Optimize model parameters
3. **Production Deployment** - Deploy and monitor models

## Best Practices

1. Systematic experimentation
2. Version control for models
3. Performance monitoring
4. A/B testing in production
