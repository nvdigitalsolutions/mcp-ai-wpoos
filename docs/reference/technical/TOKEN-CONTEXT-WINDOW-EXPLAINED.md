# Understanding Token Context Windows

## Overview

The orchestration layer manages token budgets for AI interactions. This document explains what the "Context Window" means and how it affects your AI assistant's responses.

## What is a Context Window?

The **Context Window** is the total token budget available for a complete AI interaction. Unlike what many users might expect, this limit does NOT only apply to the AI's response—it applies to the **entire conversation**.

### What's Included in the Context Window?

Every AI request uses tokens from five different sources:

1. **System Prompt** (Initial instructions)
   - The foundational instructions that define how the AI should behave
   - Example: "You are a helpful WordPress assistant"
   - Typically uses 50-500 tokens depending on complexity

2. **Conversation History** (Previous messages)
   - All prior messages in the current chat session
   - Helps the AI remember context and maintain coherent conversations
   - Can grow significantly in long conversations

3. **User Input** (Your message/question)
   - Your most recent message or command
   - Typically 10-1000 tokens depending on complexity
   - Longer questions use more tokens

4. **Tool/API Data** (WordPress information)
   - Data fetched from WordPress (posts, users, settings, etc.)
   - Information retrieved from external tools
   - Can be substantial for complex queries

5. **AI Output** (The actual response)
   - The response generated by the AI
   - This is what you see as the "answer"
   - Gets whatever tokens remain after the above

## Example Budget Allocation

For a **16,000 token** context window on a high-tier workload:

```
System Prompt:        500 tokens  (  3%)
Conversation History: 2,000 tokens (12.5%)
User Input:          1,000 tokens ( 6.25%)
Tool/API Data:       3,500 tokens (21.875%)
-------------------------------------------
Remaining for AI Output: 9,000 tokens (56.25%)
```

### Important Implications

**If your input is large, the output space shrinks:**

- Long conversation history (many back-and-forth messages) = Less space for new responses
- Complex queries requiring lots of WordPress data = Less space for detailed answers
- Verbose user input = Less space for the AI to respond

**The orchestration layer manages this automatically:**

- Monitors token usage across all components
- Prevents errors by staying within limits
- May truncate conversation history if needed
- Prioritizes current request over old context

## How to Manage Your Token Budget

### 1. Start Fresh Conversations

Long conversations consume more tokens with history. Start a new chat if you notice shorter responses.

### 2. Be Concise

Shorter, more focused questions leave more room for detailed answers.

### 3. Limit Data Requests

Requesting extensive WordPress data (many posts, users, etc.) consumes tokens. Request only what you need.

### 4. Monitor Workload Tier

Check your current tier in **Settings → WP oOS → Orchestration Layer**:

- **Low Tier** (< 128MB memory): 2,000 token context window
- **Medium Tier** (128-512MB memory): 8,000 token context window  
- **High Tier** (> 512MB memory): 32,000 token context window

### 5. Use Token Manager

Visit **Settings → WP oOS → Token Manager** for detailed token usage analytics and insights.

## Configuring Context Windows

### Per-Tier Settings

Navigate to **Settings → WP oOS → Orchestration Layer → Thresholds** to adjust:

- **Low Tier Context Window**: 500-5,000 tokens (default: 2,000)
- **Medium Tier Context Window**: 2,000-10,000 tokens (default: 8,000)
- **High Tier Context Window**: 8,000-32,000 tokens (default: 32,000)

### Per-Call and Per-Session Limits

Additional limits can be configured to prevent runaway costs:

- **Per-Call Token Limit**: Maximum tokens for a single tool call
- **Per-Session Token Limit**: Maximum cumulative tokens across an entire chat session

Enable these in **Settings → WP oOS → Orchestration Layer → Thresholds → Per-Call and Per-Session Limits**.

## Frequently Asked Questions

### Q: Why are the AI's responses getting shorter?

**A:** Your conversation history is likely consuming more tokens, leaving less room for responses. Start a fresh conversation or reduce the context.

### Q: Can I increase my context window?

**A:** Yes, if you're on a lower tier, you can:
1. Increase your PHP memory limit (if possible)
2. Manually adjust tier limits in Orchestration Layer settings
3. Enable "Disable Budget Management" for unlimited tokens (use with caution)

### Q: What's the difference between context window and max output tokens?

**A:** 
- **Context Window**: Total budget for entire interaction (input + output)
- **Max Output Tokens**: Some AI models have a separate limit just for output
- The orchestration layer manages the context window; the AI model enforces output limits

### Q: Does this apply to all AI providers?

**A:** Yes! The orchestration layer applies these limits uniformly across:
- OpenAI (GPT-3.5, GPT-4, etc.)
- Google Gemini
- Anthropic Claude
- Ollama (local AI)
- LM Studio (local AI)

## Technical Details

### How Token Counting Works

Tokens are not the same as words:
- 1 token ≈ 4 characters in English
- 1 token ≈ ¾ of a word on average
- 100 tokens ≈ 75 words

### Budget Enforcement

The `WP_MCP_AI_Resource_Manager` class determines context windows based on:

1. **Memory Tier**: Detected from PHP memory_limit
2. **Orchestration Settings**: Admin-configured limits
3. **Budget Management**: Optional dynamic adjustment
4. **Health Status**: May reduce limits if system is under stress

### Filters Available

Developers can modify limits programmatically:

```php
// Modify max tokens for specific tier
add_filter( 'wp_mcp_ai_resource_max_tokens', function( $max_tokens, $tier ) {
    if ( $tier === 'high' ) {
        return 64000; // Double the default
    }
    return $max_tokens;
}, 10, 2 );
```
