# --- Agent Memory Tools (DeepSeek V4 Phase 4/5) ---

# store_agent_context:
#   Purpose: Store important context, learnings, or information for agents to remember across sessions
#   Status: stable (comprehensive PHPUnit test coverage)
#   Recommended Settings:
#     - TTL: 30 days (default), adjust based on use case (1 hour - 1 year)
#     - Importance: Use 'high' or 'critical' for key learnings that should persist
#     - Context Types: learning, fact, preference, pattern, workflow, decision, result, insight, note, generic
#     - Tags: Use descriptive tags for easy retrieval (e.g., 'customer-preference', 'workflow-optimization')
#   Use Cases:
#     - Store user preferences across chat sessions
#     - Remember workflow decisions for consistency
#     - Capture important patterns discovered during analysis
#     - Save critical facts for future reference
#   Tool Presets: agentic_workflow, general_purpose, operations_management
#   Token Cost: Low (storage operation only)
#
# retrieve_agent_memory:
#   Purpose: Retrieve previously stored agent context with advanced search and filtering
#   Status: stable (comprehensive PHPUnit test coverage)
#   Recommended Settings:
#     - Limit: 10-20 results (default: 10, max: 50)
#     - Search Query: Use semantic search for natural language matching
#     - Filters: Combine context types, tags, importance levels for precision
#     - Include Expired: false (default) - set true only when debugging
#   Use Cases:
#     - Recall user preferences at session start
#     - Find relevant past decisions for consistency
#     - Search workflow patterns for optimization
#     - Audit agent learning history
#   Search Methods:
#     - By ID: Exact lookup for known context
#     - Semantic: Natural language query with relevance scoring
#     - Filtered: Combine multiple filters for precision
#   Tool Presets: agentic_workflow, general_purpose, operations_management
#   Token Cost: Low (retrieval operation), increases with result count
#
# Integration Recommendations:
#   - Use store_agent_context after important decisions or discoveries
#   - Call retrieve_agent_memory at session start to restore context
#   - Set appropriate TTL based on information stability
#   - Use high importance for critical learnings
#   - Tag systematically for effective filtering
#   - Monitor transient storage usage in high-volume scenarios
#
