## Screenshot Guidelines

- **Remove sensitive data**: Mask API keys, emails, real domains
- **Use test data**: Create sample assistants with generic names
- **Show full context**: Include WordPress admin sidebar and header
- **Optimize file size**: Keep under 500KB using PNG compression
- **Follow naming convention**: Use kebab-case as shown above
