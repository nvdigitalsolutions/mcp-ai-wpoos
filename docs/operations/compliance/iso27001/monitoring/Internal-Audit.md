## 1. Purpose

This procedure defines the process for conducting internal audits of the Information Security Management System (ISMS) for the NV oOS WordPress plugin, in accordance with ISO/IEC 27001:2022 requirements (Clause 9.2).

## 2. Scope

This procedure covers:
- ISMS documentation audits
- Security control implementation audits
- Process compliance audits
- Technical security audits
- Compliance with ISO/IEC 27001:2022 requirements

## 3. Audit Schedule

**Frequency:**
- **Comprehensive ISMS Audit:** Annually
- **Control-Specific Audits:** Quarterly (rotating focus)
- **Pre-Certification Audit:** 3 months before certification

**Quarterly Rotation:**
- **Q1:** Organizational & People Controls (A.5, A.6)
- **Q2:** Technological Controls (A.8)
- **Q3:** All Controls + Risk Management
- **Q4:** Business Continuity & Incident Response

## 4. Audit Process

### 4.1 Planning
- Define audit scope
- Select independent audit team
- Prepare audit plan and checklists
- Notify auditees

### 4.2 Execution
- Opening meeting
- Document review
- Interviews with personnel
- Technical testing
- Evidence collection
- Closing meeting

### 4.3 Reporting
- Analyze findings
- Classify severity (Critical/Major/Minor/OFI)
- Draft audit report
- Review and approve

### 4.4 Follow-up
- Corrective action plans developed
- Implementation tracked
- Verification of corrections
- Close findings

## 5. Finding Classification

**Non-Conformity:** Control not implemented or significant deviation  
**Opportunity for Improvement:** Control could be more effective  
**Observation:** Informational note or positive practice
