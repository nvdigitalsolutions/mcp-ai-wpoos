## 1. Purpose

This Clear Desk and Clear Screen Policy establishes security requirements for workspaces to protect sensitive information from unauthorized access, disclosure, or theft. The policy addresses both physical (clear desk) and electronic (clear screen) security measures for:

- Protection of confidential information in physical and electronic form
- Prevention of unauthorized access to sensitive data
- Reduction of social engineering risks
- Compliance with ISO/IEC 27001:2022 Control A.7.7
- Support for remote work security requirements

## 3. Clear Desk Requirements

### 3.1 General Clear Desk Policy

**End of Work Day:**
All personnel MUST ensure their workspace is clear of:

1. **Physical Documents:**
   - All papers, documents, and printed materials locked away or shredded
   - No confidential documents left on desk, printer, or scanner
   - No handwritten notes with passwords, API keys, or sensitive data
   - No Post-it notes with confidential information

2. **Electronic Media:**
   - USB drives, external hard drives, and portable storage devices locked away
   - Backup tapes or other storage media secured
   - Mobile devices secured or taken home

3. **Access Credentials:**
   - No visible passwords, PINs, or access codes
   - No authentication tokens or hardware keys left unattended
   - No key cards or badges left on desk

4. **Printed Materials:**
   - All printouts collected from printers immediately
   - Sensitive printouts shredded when no longer needed
   - No abandoned print jobs in output trays

### 3.2 During Work Hours

**When Leaving Workspace (>5 minutes):**

1. **Lock Away Documents:**
   - Place all sensitive documents in locked drawer or cabinet
   - Cover any documents that cannot be locked away

2. **Secure Devices:**
   - Lock computer screen (automatic after 5 minutes, manual if leaving)
   - Turn mobile devices face down or lock in drawer
   - Secure tablets and portable devices

3. **Remove Portable Media:**
   - USB drives disconnected and secured
   - External drives locked away if containing sensitive data

### 3.3 Home Office Requirements

**For Remote Workers:**

1. **Dedicated Workspace:**
   - Establish dedicated work area if possible
   - Avoid working in high-traffic areas (living room, kitchen)
   - Use privacy screens for laptop/monitors if in shared space

2. **Physical Security:**
   - Lock home office door when away if possible
   - Store documents in locked filing cabinet or locked room
   - Keep work materials separate from personal items

3. **Family/Roommate Awareness:**
   - Educate household members about confidential materials
   - No sharing of workspace with others during work hours
   - Lock workspace when others are present (if possible)

4. **End of Day:**
   - Clear desk of all work materials
   - Lock away physical documents
   - Store laptop and devices securely
   - Close/lock home office if applicable

### 3.4 Public Spaces

**Cafes, Hotels, Airports, Co-working Spaces:**

1. **Minimize Physical Documents:**
   - Avoid bringing printed confidential documents
   - If necessary, keep documents in secure bag at all times
   - Never leave documents unattended

2. **Workspace Vigilance:**
   - Be aware of shoulder surfers
   - Position screen away from public view
   - Use privacy screen protector (mandatory for laptops)
   - Keep workspace minimal and organized

3. **Immediate Cleanup:**
   - Pack away all materials when leaving workspace
   - Dispose of any notes securely (take home and shred)
   - Never leave materials behind

4. **No Confidential Discussions:**
   - Avoid discussing confidential matters in public
   - Use private rooms or isolated areas for sensitive calls

## 4. Clear Screen Requirements

### 4.1 Screen Lock Policy

**Automatic Screen Lock:**
- **Timeout:** Maximum 5 minutes of inactivity
- **Authentication:** Password/PIN or biometric required to unlock
- **No Disable:** Users cannot disable auto-lock feature
- **Enforcement:** Monitored through endpoint management

**Manual Screen Lock:**
- **When Leaving:** Lock screen immediately when leaving workstation
- **Keyboard Shortcut:** 
  - Windows: Windows Key + L
  - macOS: Control + Command + Q or Command + Option + Power
  - Linux: Super + L (varies by distribution)
- **Best Practice:** Lock screen even for brief absences (<1 minute)

### 4.2 Screen Privacy

**Privacy Screens:**
- **Mandatory For:** Laptops used in public spaces
- **Recommended For:** Desktop monitors in open office
- **Specification:** Reduce viewing angle to 60° or less
- **Quality:** Anti-glare, scratch-resistant filters

**Screen Positioning:**
- Position screen away from windows, doors, and walkways
- Angle monitor to prevent viewing from behind
- In public spaces, sit with back to wall if possible

### 4.3 Screen Content Management

**Minimize Sensitive Information Display:**

1. **Mask Sensitive Data:**
   - API keys show last 4 characters only
   - Passwords masked (never displayed)
   - Credit card numbers masked
   - Personal data redacted where possible

2. **Multiple Monitors:**
   - Apply same clear screen policy to all monitors
   - Lock all screens when leaving
   - Consider primary monitor for sensitive data only

3. **Presentations and Demos:**
   - Use demo accounts with fake data
   - Hide sensitive tabs/windows before screen sharing
   - Use "presenter mode" when available
   - Be aware of reflection in glasses/windows in video calls

4. **Screen Sharing:**
   - Share specific window, not entire screen
   - Close/minimize sensitive applications before sharing
   - Review visible items in taskbar/dock
   - Disable notifications during screen sharing

### 4.4 Video Conferencing

**Remote Meeting Security:**

1. **Background:**
   - Use virtual background or blur background
   - Ensure no confidential materials visible in background
   - Check for whiteboards, monitors, documents in view

2. **Screen Sharing:**
   - Share only necessary windows/applications
   - Close email, chat, and sensitive apps before sharing
   - Disable preview/thumbnails of other windows

3. **Recording:**
   - Announce if meeting is recorded
   - Ensure sensitive information not captured
   - Delete recordings containing sensitive data after use

### 4.5 Mobile Devices

**Smartphones and Tablets:**

1. **Screen Lock:**
   - Enable auto-lock after 2 minutes maximum
   - Use biometric + PIN/password
   - Require authentication on wake

2. **Public Use:**
   - Avoid viewing sensitive information in public
   - Use privacy screen protector
   - Be aware of shoulder surfers
   - Minimize screen brightness in public if viewing sensitive data

3. **Notifications:**
   - Disable sensitive notifications on lock screen
   - Configure "Do Not Disturb" for sensitive meetings

## 5. Document Handling

### 5.1 Printing

**Secure Printing:**

1. **Print Only When Necessary:**
   - Avoid printing confidential documents if possible
   - Use digital copies when feasible

2. **Immediate Collection:**
   - Collect printouts from printer immediately
   - Never leave print jobs unattended
   - Check printer output tray before leaving

3. **Secure Print Feature:**
   - Use pull-printing if available (released only when user at printer)
   - Configure printer to require authentication

4. **Home Printing:**
   - Avoid printing highly confidential information at home
   - If necessary, shred immediately after use
   - Use personal printer, not shared household printer

### 5.2 Document Disposal

**Secure Disposal:**

1. **Shredding:**
   - **Requirement:** Cross-cut shredder (minimum P-4 security level)
   - **What to Shred:** All documents marked Confidential or Restricted
   - **Home Office:** Use personal cross-cut shredder
   - **Office:** Use designated secure shred bins

2. **Electronic Disposal:**
   - Securely delete files (not just move to trash)
   - Overwrite deleted space if highly sensitive
   - Degauss/destroy drives when disposing of hardware

3. **Interim Storage:**
   - If unable to shred immediately, lock in secure container
   - Shred within 24 hours

### 5.3 Document Transport

**Carrying Documents:**

1. **Secure Bags:**
   - Use locked briefcase or bag with zipper
   - Never carry loose confidential documents

2. **Vehicle Transport:**
   - Keep documents in trunk, not visible in vehicle
   - Lock vehicle at all times
   - Remove documents from vehicle overnight

3. **Public Transit:**
   - Keep bag/briefcase with you at all times
   - Be aware of surroundings
   - Avoid reviewing confidential documents while traveling

## 6. Visitor Management

### 6.1 Workspace Visitors

**When Visitors Present:**

1. **Clear Visible Information:**
   - Remove or cover confidential documents
   - Lock screen or close sensitive applications
   - Turn monitors away from visitor if possible

2. **Escort Requirements:**
   - Visitors must be escorted at all times
   - Monitor visitor proximity to workstations
   - Ensure visitor does not access systems or documents

3. **Meeting Rooms:**
   - Clear whiteboards after meetings
   - Collect all handouts
   - Ensure no confidential materials left behind

### 6.2 Home Office Visitors

**Service Personnel (repair, delivery, etc.):**

1. **Before Visit:**
   - Lock away all work materials
   - Lock home office if possible
   - Shut down or lock computers

2. **During Visit:**
   - Accompany service personnel at all times
   - Do not allow access to work area if possible
   - Keep work materials out of sight

3. **After Visit:**
   - Verify all materials remain secure
   - Check for any disturbances

## 7. Compliance and Enforcement

### 7.1 User Responsibilities

All users MUST:

1. **Comply with Policy:** Follow all clear desk and clear screen requirements
2. **Report Violations:** Report observed violations to manager or security team
3. **Report Incidents:** Report any potential breach (e.g., document left on desk discovered by unauthorized person)
4. **Training:** Complete annual clear desk/screen training
5. **Acknowledgment:** Acknowledge policy understanding annually

### 7.2 Management Responsibilities

Managers MUST:

1. **Enforce Policy:** Ensure team members comply with policy
2. **Lead by Example:** Demonstrate clear desk/screen practices
3. **Conduct Spot Checks:** Periodic visual checks of workspaces
4. **Address Violations:** Take corrective action for non-compliance

### 7.3 Security Team Responsibilities

Security team will:

1. **Conduct Audits:** Quarterly clear desk audits (random checks)
2. **Provide Training:** Annual training on policy requirements
3. **Monitor Compliance:** Track compliance metrics
4. **Investigate Incidents:** Investigate any security incidents related to clear desk/screen violations

### 7.4 Violations and Consequences

**First Offense:**
- Verbal reminder and re-training
- Documentation in personnel file

**Second Offense:**
- Written warning
- Mandatory additional training
- 30-day monitoring period

**Third Offense:**
- Formal disciplinary action
- Possible suspension or termination (depending on severity)

**Serious Violations:**
- Immediate disciplinary action up to termination
- Examples: Intentional disclosure, repeated violations after warnings

## 8. Audit and Monitoring

### 8.1 Clear Desk Audits

**Frequency:** Quarterly random audits

**Audit Process:**

1. **Unannounced Checks:**
   - Security team conducts random workspace checks
   - Check physical workspaces, printers, common areas
   - Document findings

2. **Assessment Criteria:**
   - No confidential documents visible
   - Screens locked when unattended
   - No passwords/credentials visible
   - Printers clear of documents
   - Storage areas locked

3. **Scoring:**
   - Compliant: No violations found
   - Minor: 1-2 low-risk items (e.g., internal document visible)
   - Major: 3+ items or high-risk item (e.g., password written down)

4. **Follow-up:**
   - Compliant: No action
   - Minor: Friendly reminder, no documentation
   - Major: Formal notification, training required

### 8.2 Screen Lock Monitoring

**Automated Monitoring:**

- Endpoint management tools monitor screen lock compliance
- Alert if auto-lock disabled or timeout exceeds 5 minutes
- Monthly compliance reports generated

**Metrics:**
- % of devices with compliant screen lock settings
- Average time to screen lock
- Number of violations detected

### 8.3 Reporting

**Quarterly Reports to Management:**
- Clear desk audit results
- Screen lock compliance metrics
- Violations and corrective actions
- Training completion rates
- Improvement recommendations

## 10. Exceptions

### 10.1 Exception Process

Exceptions to this policy require:

1. **Written Request:** Submit to CISO with business justification
2. **Risk Assessment:** Security team assesses risk
3. **Approval:** CISO approval required
4. **Compensating Controls:** Alternative security measures required
5. **Documentation:** Exception documented with review date
6. **Periodic Review:** Re-evaluate every 6 months

### 10.2 Temporary Exceptions

Short-term exceptions (e.g., during incident response):

- Approval by CISO or designated alternate
- Maximum 30 days
- Document justification and controls
- Automatic expiration

## Appendix B: Screen Lock Configuration

### Windows Configuration

**Group Policy Settings:**
```
Computer Configuration > Policies > Windows Settings > Security Settings > Local Policies > Security Options
- Interactive logon: Machine inactivity limit: 300 seconds (5 minutes)

User Configuration > Policies > Administrative Templates > Control Panel > Personalization
- Enable screen saver: Enabled
- Screen saver timeout: 300 seconds
- Password protect the screen saver: Enabled
```

### macOS Configuration

**Terminal Commands:**
```bash
# Set screen lock timeout to 5 minutes
defaults write com.apple.screensaver idleTime 300

# Require password immediately after sleep or screen saver begins
defaults write com.apple.screensaver askForPassword -int 1
defaults write com.apple.screensaver askForPasswordDelay -int 0
```

### Linux Configuration

**GNOME:**
```bash
gsettings set org.gnome.desktop.session idle-delay 300
gsettings set org.gnome.desktop.screensaver lock-enabled true
gsettings set org.gnome.desktop.screensaver lock-delay 0
```
