Tab URLs

Each tab has a unique URL that can be bookmarked or shared:

  • ?page=nvoos-pro-dashboard&tab=overview - Overview (default)
  • ?page=nvoos-pro-dashboard&tab=iso27001 - ISO 27001 Controls
  • ?page=nvoos-pro-dashboard&tab=reports - Compliance Reports
  • ?page=nvoos-pro-dashboard&tab=monitoring - Security Monitoring
  • ?page=nvoos-pro-dashboard&tab=risk - Risk Management
  • ?page=nvoos-pro-dashboard&tab=multi-framework - Multi-Framework

💡 Developer Note:

This implementation uses WordPress native tab styling and follows WordPress admin UI best practices. All tabs are rendered server-side with PHP, ensuring consistent behavior and no JavaScript dependencies for basic functionality.
