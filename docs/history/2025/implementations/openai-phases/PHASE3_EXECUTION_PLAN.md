**Goal**: Establish pattern with 5 representative professions

**Selected Professions** (diverse representation):
1. **physician** - Complex licensing, board certifications, varied specialties
2. **nurse** - State/country licensing, practice scope variations
3. **pharmacist** - Formulary differences, dispensing regulations
4. **physical_therapist** - PT vs physiotherapist terminology, practice rights
5. **clinical_research_coordinator** - IRB/ethics requirements by region

**Regional Coverage** (all 5):
- US: State licensing boards, board certifications, Medicare/Medicaid

**Content Additions** (per profession):

  - Licensing/registration requirements
  - Scope of practice variations
  - Professional standards bodies
  - Healthcare system differences
  - Key regional protocols/guidelines
- Estimated: 1.5-2 hours per profession = 8-10 hours total
