# Developer — Testing

Testing strategies, coverage dashboards, and test guides.

## What belongs here

- Code coverage dashboard
- Cron testing guide
- Performance testing guide
- Chat optimization testing
- AJAX test suite and inventory
- Manual test guides for OAuth and dashboards

## What doesn't belong here

- PHPUnit test source code → `../../tests/` at repository root
- Test profession/team pages → those are user-facing test tools
- Quality metrics → `../../project/code-reviews/`
