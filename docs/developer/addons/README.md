# Developer — Addons

Documentation for installable addons that extend NV oOS.

## What belongs here

- Chat SPA — React replacement for the legacy chat shortcode
- Docs Hub — in-site documentation SPA
- Toolkit SPA Blueprint — standard pattern for all SPA addons

## What doesn't belong here

- Addon source code → `../../addons/` at the repository root
- Pro addon docs → those ship inside each addon's own `docs/` folder
- Integration guides for external services → `../integration/`
