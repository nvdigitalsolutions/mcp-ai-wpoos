# Current Fixes

This directory is reserved for **current, active fix documentation** that is being worked on or recently completed.

## Purpose

Use this directory for:
- Fixes currently in development
- Recently merged fixes (last 30 days)
- Quick reference for ongoing issue resolution

## When to Add Documentation Here

Add fix documentation to this directory when:
1. **Working on a bug fix** - Document the problem and solution approach
2. **Fix just merged** - Keep recent fixes here for easy reference
3. **Needs visibility** - Important fixes that teams need to be aware of

## When to Archive

Move documentation to `archive/fixes/` when:
- Fix is older than 30 days
- Fix is well-established and verified
- No active discussion or iteration needed

## Documentation Guidelines

Each fix document should include:
- **Problem Statement** - Clear description of the bug/issue
- **Root Cause** - Why the problem occurred
- **Solution** - What was changed to fix it
- **Testing** - How to verify the fix works
- **Related Issues** - Links to GitHub issues, PRs, or discussions
