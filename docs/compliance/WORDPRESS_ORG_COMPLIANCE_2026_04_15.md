## Guideline 3 — Plugins Must Not Embed External Links on the Public Site Without Permission

**Status:** ✅ PASS

### Evidence

- **No "Powered by" attribution links** injected into user-facing output.
- Searched all `includes/`, `assets/js/`, `assets/css/` for "powered by" patterns — only found in admin-facing descriptions (e.g., "AI-powered search… Powered by Perplexity's Sonar models" in `class-wp-mcp-ai-admin-settings.php:285`) and block registration descriptions (`assets/js/blocks/chat-bubble-block.js:43`). These are admin labels, not injected frontend links.
- Shortcode output is generated by `WP_MCP_AI_Shortcode::render_shortcode()` which individually escapes every dynamic value at the point of insertion using `esc_attr()`, `esc_html()`, `esc_url()`, etc. No external links are injected.
- Block render files (`includes/blocks/chat/render.php`, `includes/blocks/chat-bubble/render.php`, `includes/blocks/professional-selector/render.php`) echo shortcode output directly. Each `echo` is annotated with a `phpcs:ignore WordPress.Security.EscapeOutput.OutputNotEscaped` comment explaining that the shortcode handler self-sanitizes all values, and that `wp_kses_post()` cannot be used because it strips `data-*` attributes, SVGs, `<form>`/`<input>`/`<button>` element attributes, and `<script type="application/json">` config blocks required by the chat UI.
- Elementor widget render methods (`class-wp-mcp-ai-elementor-widget.php`, `class-wp-mcp-ai-elementor-chat-bubble-widget.php`, `class-wp-mcp-ai-elementor-professional-selector-widget.php`, `class-wp-mcp-ai-elementor-telegram-login-widget.php`) echo shortcode output directly with the same `phpcs:ignore` justification.
- The AJAX endpoint in `class-wp-mcp-ai-professional-selector-shortcode.php` still wraps its `do_shortcode()` response in `wp_kses_post()` because the AJAX JSON response does not require `data-*` attributes or complex HTML structures.

### 13g. `do_shortcode()` Output Handling

All `do_shortcode()` calls that produce user-facing output are handled using one of two strategies:

**Strategy 1 — Direct echo with `phpcs:ignore` justification:** Used when the shortcode output contains complex HTML structures (`data-*` attributes, SVGs, `<form>`/`<input>`/`<button>` elements, `<script type="application/json">` config blocks) that `wp_kses_post()` would destroy:

| File | Handling | Justification |
|------|----------|---------------|
| `includes/blocks/chat/render.php:71` | `echo do_shortcode(...)` | `render_shortcode()` escapes all values individually; `wp_kses_post()` strips `data-*` attrs, SVGs, form elements, JSON config blocks |
| `includes/blocks/chat-bubble/render.php:218` | `echo $safe_html` (with deferred attr rename) | Same as above; regex renames `data-wp-mcp-ai-chat` for lazy init |
| `includes/blocks/professional-selector/render.php:81` | `echo do_shortcode(...)` | `render_shortcode()` escapes all values; output includes `<script type="application/json">` config blocks |
| `includes/elementor/class-wp-mcp-ai-elementor-widget.php:1202` | `echo do_shortcode(...)` | Same as blocks/chat/render.php |
| `includes/elementor/class-wp-mcp-ai-elementor-chat-bubble-widget.php:866` | `echo $safe_html` (with deferred attr rename) | Same as blocks/chat-bubble/render.php |
| `includes/elementor/class-wp-mcp-ai-elementor-professional-selector-widget.php:411` | `echo do_shortcode(...)` | Same as blocks/professional-selector/render.php |
| `includes/elementor/class-wp-mcp-ai-elementor-telegram-login-widget.php:267` | `echo do_shortcode(...)` | Telegram SDK `<script>` embed; `wp_kses_post()` strips it entirely |
| `includes/admin/class-wp-mcp-ai-admin-profession-research-page.php:226` | `echo do_shortcode(...)` | Admin context; shortcode self-sanitizes |
| `includes/admin/class-wp-mcp-ai-admin-team-research-page.php:231` | `echo do_shortcode(...)` | Admin context; shortcode self-sanitizes |
| `includes/class-wp-mcp-ai-chat-bubble-frontend.php:372` | `echo $safe_html` (with deferred attr rename) | Same as blocks/chat-bubble/render.php |

> **Why `wp_kses_post()` cannot be used here:** The chat UI renders a complex interactive application including `data-assistant-id`, `data-mode`, `data-status`, `data-selector-config`, and 15+ other `data-*` attributes; inline SVG icons; `<form>`, `<input>`, `<button>`, and `<textarea>` elements with event handlers; and `<script type="application/json">` blocks containing configuration JSON. `wp_kses_post()` strips all of these, rendering the UI non-functional. The shortcode's `render_shortcode()` method individually escapes every dynamic value at the point of insertion using `esc_attr()`, `esc_html()`, `esc_url()`, `wp_json_encode()`, etc.

**Strategy 2 — `wp_kses_post()` wrapping:** Used where the output is simple HTML without complex structures:

| File | Handling |
|------|----------|
| `includes/class-wp-mcp-ai-professional-selector-shortcode.php:582` | `'html' => wp_kses_post( $html )` — AJAX JSON response |
| `includes/tools/class-wp-mcp-ai-tool-store-agent-context.php:497` | Internal processing only — `do_shortcode()` → `wp_strip_all_tags()` for plain-text extraction, never output to user |

## Additional Security Measures (Beyond Guidelines)

### Encryption

- `WP_MCP_AI_Encryption` class provides AES-256-CBC encryption for sensitive stored data.
- Encryption key generated from `random_bytes(32)` and stored as a WordPress option.
- API keys can be encrypted at rest.

### Rate Limiting

- Built-in rate limiting per user and per IP.
- Token usage tracking with configurable TPM (tokens per minute) budgets.
- Cost attribution and tracking per assistant.

### Capability-Based Access Control

- 336 `current_user_can()` checks enforce WordPress role-based access.
- Tool definitions declare `required_capability` (e.g., `edit_posts`, `manage_options`).
- Guest access controlled via separate `guest_request` context flag with explicit tool allowlisting.

### Content Security

- All user-generated content processed through WordPress sanitization APIs.
- File uploads validated for MIME type, size, and extension.
- SVG uploads disabled by default (configurable).
