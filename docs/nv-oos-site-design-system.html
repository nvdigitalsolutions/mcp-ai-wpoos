01 · Foundations

Colour, by role

Every colour ships as a CSS custom property under :root. Never hardcode hex in components — reference the token. The palette splits into four families: navy (dark surfaces), teal (the accent), blue (the "mint" secondary), and neutrals.

Do: reference tokens everywhere (var(--accent)), keep dark surfaces on the navy family, and pair teal only as accent — never as a fill for large light backgrounds.
Don't: introduce new hues without a token, use pure black text, or put accent-bright on light backgrounds (it belongs on dark).
02 · Typography & voice

Two typefaces, one voice

Plus Jakarta Sans is the display face — every heading, number, and brand word. Inter Tight carries body copy. The signature voice move: the last phrase of every heading is italic teal — accent-bright on dark, accent-deep on light.

05 · Layout, responsive & print

The grid rules, and the type math

One container (.wrap, 1180px, fluid padding), sections that alternate white and cream-dark, and a mobile type scale that grows the whole page by 25% — plus a single-sheet A4 print mode.
RuleSpecBehaviour
Container.wrap { max-width: 1180px; padding-inline: clamp(1.1rem, 3.5vw, 2rem) }Single fluid container; never nested full-bleed inside cards
Section rhythm.section { padding: clamp(2.2rem, 5vw, 3.2rem) 0 }Alternate --white / --cream-dark; dark bands break the rhythm deliberately
Gridstoolkit 3-col · flow 5-col · steps 3-col · model/qa 2-col · stats 4-colCollapse: 2-col at 1024px → 1-col at 560px
Breakpoints1024 / 860 / 720 / 5601024: grids halve · 860: nav brand shrinks · 720: asides left-align · 560: everything single-column
Type scalehtml 17.5px desktop → 22px ≤720px (+25%)All rem sizes and clamp() floors scale together — body syncs at 20.5px
Print@page A4, 12mm; html 16px; body 10.5ptTopnav & buttons hidden; sections avoid page breaks; single-sheet friendly
Motiontransform 0.25s, box-shadow 0.25s, border-color 0.25sHover lifts cards -4px with teal border + soft shadow; no other motion
Do: keep every page to the same section rhythm, use the stats strip right after the hero, and end marketing pages with the CTA card + navy footer.
Don't: put light cards on dark bands (use glass cards), mix a third typeface, or animate anything besides the card hover lift.
