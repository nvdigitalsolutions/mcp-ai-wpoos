Unit suite: 98 tests / 513 assertions OK.
- **#6603** — **Vendor-authoritative price display + $34.99 fallback**: the purchase modal now syncs its price label from the vendor `/session` response (`amount` + `currency`, `Intl.NumberFormat`, display-only — the vendor re-verifies server-side); `Payments::DEFAULT_PRICE_CENTS` and the checkout-api `DEFAULT_PRICE_CENTS` (fresh installs) move **4900 → 3499 cents**; `CommerceTest::defaultPriceIs3499Cents` pins it. Test-bootstrap hardening: when `WP_TESTS_DIR` is unset, the plugin's own pristine vendored wp-phpunit lib is preferred over the shared temp lib (the root bootstrap's PHPUnit-11 patch persists to disk and fatals this plugin's locked PHPUnit 9.6 — the `::name()` investigation).
