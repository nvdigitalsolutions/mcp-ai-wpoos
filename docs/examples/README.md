# WP oOS Documentation Examples

This directory contains HTML example files and interactive demonstrations for various WP oOS features.

## Available Examples

### Console Testing

- **[console-testing-example.html](console-testing-example.html)** - Interactive example demonstrating how to use the `wpMcpAiTestGetTranscript()` console function to test the chat transcripts GET endpoint.

### Chat Templates

- **[chat-templates-demo.html](chat-templates-demo.html)** - Visual reference guide for the three available chat interface templates (Classic, Speech Bubbles, and Compact). Includes usage examples, use cases, and technical specifications.

## How to Use

These HTML files can be:

1. **Opened directly in a browser** - Just double-click the HTML file or open it with your web browser
2. **Served via local web server** - For a more realistic testing environment
3. **Referenced in documentation** - These examples supplement the main documentation

## Adding New Examples

When adding new example files:

1. Create a descriptive HTML file name (e.g., `feature-name-example.html`)
2. Include clear comments and inline documentation
3. Add entry to this README
4. Reference the example in related documentation files

## Note

These examples are for demonstration and learning purposes. To actually use the WP oOS features, you need to:

1. Have the WP oOS plugin installed and activated on a WordPress site
2. Be on a page where the relevant JavaScript is loaded
3. Have appropriate user permissions
