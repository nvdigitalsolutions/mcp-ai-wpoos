WP oOS Chat Templates

Visual Reference for Available Chat Interface Layouts

Classic Template

Default

Standard chat interface with balanced spacing and clean design.

[mcp_ai_chat assistant="123" template="classic"]

[mcp_ai_chat assistant="123"]
Use Cases:
  • General-purpose chat widgets
  • Customer support interfaces
  • Landing page assistants
  • Full-featured chat experiences

Speech Bubbles Template

New

Comic-book style with distinctive speech tails.

[mcp_ai_chat assistant="123" template="speech-bubbles"]
Use Cases:
  • Creative or playful brands
  • Educational chatbots
  • Entertainment interfaces
  • Conversational emphasis
Design Note: User messages have tails pointing right, assistant messages point left.

Compact Template

New

Minimalist layout with reduced spacing for tight spaces.

[mcp_ai_chat assistant="123" template="compact"]
Use Cases:
  • Sidebar widgets
  • Mobile interfaces
  • Dashboard integrations
  • Quick Q&A surfaces
Space Savings: ~40% smaller than classic (480px vs 720px width, reduced padding)

Sidebar Template

New

ChatGPT-style layout with persistent conversation history sidebar.

[mcp_ai_chat assistant="123" template="sidebar"]
Use Cases:
  • Full-page chat applications
  • AI assistant dashboards
  • Multi-conversation management
  • Enterprise chat interfaces
Layout: Two-column grid with 260px sidebar on left showing conversation history, chat area on right.

Template Features & Specifications

Classic Template

  • Max width: 720px
  • Padding: 20px
  • Message height: 360px max
  • Border radius: 20px
  • Full feature support

Speech Bubbles Template

  • Based on Classic template dimensions
  • CSS pseudo-elements (::after) for tails
  • User bubbles: tail on bottom-right
  • Assistant bubbles: tail on bottom-left
  • Tool/system messages: no tails
  • Enhanced shadow for 3D effect

Compact Template

  • Max width: 480px (33% smaller)
  • Padding: 12px (40% smaller)
  • Message height: 240px max (33% smaller)
  • Font size: 0.875rem (14px)
  • Buttons: 32px (vs 40px in classic)
  • Avatars hidden by default

Sidebar Template

  • Max width: 1200px (two-column layout)
  • Grid: 260px sidebar + flexible chat area
  • Min height: 600px for optimal UX
  • Persistent conversation history on left
  • ChatGPT-inspired design
  • Responsive: Stacks vertically on mobile (<768px)
  • History sidebar always visible (no toggle)

Implementation Details

  • CSS-Driven: No JavaScript changes required
  • Data Attribute: data-template="[template-name]"
  • CSS Class: .wp-mcp-ai-chat--template-[template-name]
  • Browser Support: All modern browsers (Chrome, Firefox, Safari, Edge)
  • Accessibility: All ARIA attributes maintained
  • Performance: No additional HTTP requests

Block Editor

  • Select chat block in editor
  • Find "Template" dropdown in block settings
  • Choose: Classic, Speech Bubbles, Compact, or Sidebar
  • Preview updates automatically
