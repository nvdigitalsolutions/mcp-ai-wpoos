🧪 WP oOS Console Testing Utility

This page demonstrates how to use the wpMcpAiTestGetTranscript() console function to test the chat transcripts GET endpoint.

⚠️ Note: This is a demonstration page. To actually use the testing utility, you need to be on a WordPress page where the WP oOS chat JavaScript is loaded.

📝 Quick Start

  1. Open your browser's Developer Console (F12 or Right-click → Inspect → Console)
  2. Navigate to a page with the WP oOS chat widget
  3. Run the test function with your session key

💡 Examples

Example 1: Test with session key, user ID, and assistant ID 
wpMcpAiTestGetTranscript('1e05412c-c158-44c1-8f8d-584c9f29a1e9', 1, 14)

This makes a GET request to:
/wp-json/mcp-ai/v1/chat-transcripts/1e05412c-c158-44c1-8f8d-584c9f29a1e9?user_id=1&assistant_id=14

Example 2: Test with only session key (uses current user) 
wpMcpAiTestGetTranscript('1e05412c-c158-44c1-8f8d-584c9f29a1e9')

This makes a GET request to:
/wp-json/mcp-ai/v1/chat-transcripts/1e05412c-c158-44c1-8f8d-584c9f29a1e9

Example 3: Using async/await 
const result = await wpMcpAiTestGetTranscript('abc-123-def-456', 5);
console.log('Transcript data:', result);
Example 4: Using .then() / .catch() 
wpMcpAiTestGetTranscript('1e05412c-c158-44c1-8f8d-584c9f29a1e9')
    .then(data => console.log('Success:', data))
    .catch(err => console.error('Error:', err));

🔧 Parameters

Parameter Type Required Description
sessionKey string ✅ Yes The session key/UUID of the chat transcript
userId number ❌ No User ID who owns the transcript (defaults to current user)
assistantId number ❌ No Assistant ID to filter by

🚨 Common Issues

Error: "sessionKey parameter is required"

You must provide the session key as the first parameter:

// ❌ Wrong
wpMcpAiTestGetTranscript()

// ✅ Correct
wpMcpAiTestGetTranscript('1e05412c-c158-44c1-8f8d-584c9f29a1e9')

Error: "transcriptsEndpoint not configured"

The chat JavaScript hasn't loaded yet. Make sure you're on a page with the WP oOS chat widget.

404 Not Found

  • The transcript doesn't exist
  • The session key is incorrect
  • JetEngine is not installed (transcripts only stored when JetEngine is active)
  • User ID or Assistant ID doesn't match

401 Unauthorized

  • You're not logged in
  • The WordPress nonce has expired (try refreshing the page)
