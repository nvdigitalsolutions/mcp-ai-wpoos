🔧 Professional Selector Chat Form Fix

⚠️The Problem

When users submitted a chat message in the professional selector widget, the page would refresh instead of handling the submission via JavaScript.

1 User selects professional, provider, and model
2 Clicks "Start Chat" button
3 JavaScript loads chat interface via AJAX
4 Chat HTML is inserted into the page dynamically
5 ❌ Problem: Chat form has no event handlers
6 ❌ User submits message → Page refreshes

✅The Solution

We exposed a public init API in chat.js and called it after dynamically inserting chat HTML.

Code Changes

1. chat.js - Expose Public Init API

// Before: No public API
if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', initWithCronStatus);
} else {
    initWithCronStatus();
}

// After: Added public API for dynamic initialization
if (!window.wpMcpAiChatInit) {
    window.wpMcpAiChatInit = {
        /**
         * Initialize or reinitialize chat instances.
         * Call this after dynamically inserting chat HTML into the page.
         */
        init: initWithCronStatus
    };
}

if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', initWithCronStatus);
} else {
    initWithCronStatus();
}

2. professional-selector.js - Call Init After Inserting HTML

// Before: Just inserted HTML without initialization
success: function(response) {
    if (response.success && response.data.html) {
        $chatWrapper.html(response.data.html);
        ProfessionalSelector.showChatContainer($container);
    }
}

// After: Added initialization call
success: function(response) {
    if (response.success && response.data.html) {
        $chatWrapper.html(response.data.html);
        ProfessionalSelector.showChatContainer($container);
        // Initialize the dynamically inserted chat interface
        ProfessionalSelector.initializeChatInterface();
    }
}

// New method added to ProfessionalSelector:
initializeChatInterface: function() {
    // Check if the chat init API is available
    if (typeof window.wpMcpAiChatInit !== 'undefined' && window.wpMcpAiChatInit.init) {
        // Call the chat initialization function
        window.wpMcpAiChatInit.init();
    } else if (window.console && console.warn) {
        console.warn('[Professional Selector] Chat initialization API not available.');
    }
}

How It Works Now

❌ Before (Broken)

  4. Chat doesn't work

✅ After (Fixed)

  2. Init API called automatically
  3. Event handlers attached
  4. Form submit → preventDefault()
  5. Chat works correctly!

Technical Details

// The init() function checks for already-initialized containers
function init() {
    const containers = document.querySelectorAll('[data-wp-mcp-ai-chat]');
    Array.prototype.forEach.call(containers, function (container) {
        // Skip if already initialized
        if (container.hasAttribute('data-wp-mcp-ai-initialized')) {
            return;
        }
        // ... attach event handlers ...
        form.addEventListener('submit', function (event) {
            handleSubmit(event, state);
        });
        // ... mark as initialized ...
        container.setAttribute('data-wp-mcp-ai-initialized', 'true');
    });
}

This means calling init() multiple times is safe - it will only initialize containers that haven't been initialized yet.
