NV oOS Gateway

A ChatGPT and Codex plugin from NV Digital Solutions that connects to the public NV oOS MCP Gateway — explore the public NV oOS demo site through namespaced demo_* tools: environment status, deep research with citations, and the content and store tools the demo operator exposes.

About the plugin

After a one-time OAuth consent, the plugin reaches the fleet gateway at mcp.nvoos.pro, which scopes access per site. This plugin exposes the public demo site only — never private client sites. The gateway enforces rate limits and policy rules on every call.
