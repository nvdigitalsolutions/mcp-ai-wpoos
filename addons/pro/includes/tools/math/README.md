# Math Toolkit

> Mathematical computation, symbolic algebra, graphing, and logic evaluation.

## Purpose

Self-contained mathematical tools for calculus (derivatives, integrals), equation solving, matrix operations, function graphing, logic gate evaluation, and truth table generation.

## Tool Inventory

| Tool | Slug | Description |
|------|------|-------------|
| Calculate Derivative | `calculate_derivative` | Symbolic differentiation of mathematical expressions |
| Calculate Integral | `calculate_integral` | Symbolic integration (definite and indefinite) |
| Evaluate Logic Gate | `evaluate_logic_gate` | Evaluate a logic gate circuit expression |
| Generate Truth Table | `generate_truth_table` | Produce truth tables for Boolean expressions |
| Graph Function | `graph_function` | Plot a mathematical function as an image |
| Matrix Operations | `matrix_operations` | Perform matrix arithmetic and transformations |
| Render Math Equation | `render_math_equation` | Render a LaTeX equation as an image |
| Simplify Expression | `simplify_expression` | Algebraically simplify a mathematical expression |
| Solve Equation | `solve_equation` | Solve algebraic equations symbolically |

## Dependencies

- WordPress 6.0+
- PHP 8.1+ (for expression parsing libraries)

## Registration

Registered in `wp_mcp_ai_pro_register_tools()` in `addons/pro/mcp-ai-wpoos-pro.php`.
