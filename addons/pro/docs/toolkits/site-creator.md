# Site Creator Toolkit

> AI-driven site building: landing pages, hero/CTA/feature/gallery sections, navigation,
> footers, sidebars, and full template kits. 27 tools.

| | |
|---|---|
| **Activation setting** | `enable_site_creator_toolkit` |
| **Admin location** | NV oOS → Settings → Pro Features → Site Creator |
| **Tools** | 27 |
| **Available since** | Pro v1.2.0 |

---

## Tool categories

- **Site planning:** `generate_site_plan`, `analyze_competitor_sites`,
  `automate_development_workflow`
- **Pages:** `generate_landing_page`, `create_homepage_layout`, `create_service_pages`,
  `build_about_page`, `generate_blog_layout`
- **Sections:** `create_hero_section`, `create_cta_section`, `generate_feature_section`,
  `generate_gallery_section`, `build_testimonial_section`, `build_contact_section`
- **Navigation & layout:** `build_navigation_menu`, `create_footer_widget`,
  `generate_sidebar_widget`
- **Widgets & kits:** `create_custom_widget`, `export_template_kit`

Tool source: `addons/pro/includes/tools/site-creator-toolkit/`.

---

## Activation

1. Activate the Pro add-on.
2. Toggle **Site Creator Toolkit** under **NV oOS → Settings → Pro Features**.
