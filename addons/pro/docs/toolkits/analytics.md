# Advanced Analytics Toolkit

> Business intelligence and predictive analytics: dashboards, KPIs, cohort and funnel
> analysis, churn prediction, attribution modeling, and ML customer segmentation.

| | |
|---|---|
| **Activation setting** | `enable_analytics_toolkit` |
| **Admin location** | NV oOS → Settings → Pro Features → Analytics |
| **Tools** | 12 |
| **NPM** | `d3`, `mathjs`, `regression`, `fast-csv`, `chart.js` |

---

## Tools

- **Dashboards & reports:** `generate_executive_dashboard`, `create_custom_report`,
  `collect_custom_metrics`, `export_analytics_api`
- **Modeling:** `cohort_analysis`, `funnel_analysis`, `revenue_forecast`,
  `churn_prediction`, `attribution_modeling`, `customer_segmentation_ml`
- **Real-time / sync:** `real_time_event_tracking`, `data_warehouse_sync`

Tool source: `addons/pro/includes/tools/analytics/`.

---

## Activation

1. Activate the Pro add-on.
2. Toggle **Analytics Toolkit** under **NV oOS → Settings → Pro Features**.
3. Configure data sources (WordPress, WooCommerce, custom DBs, GA4, etc.) on the toolkit
   settings page.
