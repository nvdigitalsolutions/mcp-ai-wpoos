# Social Media Management Toolkit

> Multi-platform social-media automation: cross-platform posting, scheduling, listening,
> moderation, hashtag tracking, influencer ID, competitor analysis, and analytics.

| | |
|---|---|
| **Activation setting** | `enable_social_media_toolkit` |
| **Admin location** | NV oOS → Settings → Pro Features → Social Media |
| **Tools** | 15 |
| **NPM** | `twitter-api-v2`, `facebook-node-sdk`, `linkedin-api-client`, `axios` |

---

## Tool categories

- **Publishing:** `post_to_multiple_platforms`, `schedule_social_post`,
  `bulk_schedule_posts`, `create_content_calendar`, `create_social_video`,
  `auto_optimize_images`
- **Engagement:** `monitor_mentions_replies`, `auto_respond_messages`,
  `moderate_comments`
- **Discovery & insight:** `social_listening_trends`, `track_hashtag_performance`,
  `competitor_analysis`, `influencer_identification`, `generate_post_ideas`
- **Analytics:** `get_cross_platform_analytics`

Tool source: `addons/pro/includes/tools/social-media/`.

---

## Activation

1. Activate the Pro add-on.
2. Toggle **Social Media Toolkit** under **NV oOS → Settings → Pro Features**.
3. Add OAuth credentials per platform on the toolkit settings page; store secrets in
   the [Password Vault](password-vault.md).
