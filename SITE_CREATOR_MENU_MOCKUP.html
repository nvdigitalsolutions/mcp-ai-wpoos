Site Creator Toolkit

About Site Creator Toolkit

The Site Creator Toolkit provides advanced AI-powered tools for automated WordPress site creation, following industry best practices and modern standards. It integrates with the Architect Agent for self-editing capabilities and automated development workflows.

Available Tool Categories

  • Research & Discovery (4 tools) - Web search for best practices, competitor analysis, site planning, template suggestions
  • Page Building (5 tools) - Landing pages, homepage layouts, about pages, service pages, blog layouts
  • Section Building (6 tools) - Hero sections, features, testimonials, CTAs, galleries, contact sections
  • Widget Building (4 tools) - Custom widgets, navigation menus, sidebar widgets, footer widgets
  • Template Management (4 tools) - Save/import/export templates, version control
  • Integration Tools (3 tools) - Architect Agent integration, theme scaffolding, automated workflows

Configuration

To enable or disable this toolkit, go to Settings → NV oOS → Tools and toggle the "Enable Site Creator Toolkit" option.
