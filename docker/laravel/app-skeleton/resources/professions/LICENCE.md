## How this directory is produced

Generated by `bin/sync-professions.php` from the WordPress base set, then
committed. Do not edit these files by hand: the CI gate
(`php bin/sync-professions.php --check`) fails when they no longer match the
source, and names each stale file.

## Not included

The six `pro-*` packs are supplied under a separate entitlement. A deployment
that has them points `OOS_PROFESSIONS_PATH` at a directory containing this base
set plus the packs.
